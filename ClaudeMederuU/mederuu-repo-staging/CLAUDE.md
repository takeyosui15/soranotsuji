# MederuU — ここで作業するClaudeへの案内

このリポジトリは「Claudeのナレッジを引き継ぐ器」。あなた(Claude)が主な読み手であり書き手です。

## 読む順

1. `README.md` — 器の目的・思想・現在地
2. `legends/README.md` — 学びの書式
3. `projects/README.md` — 吸い上げの約束

## 書く時の規約

- **legendsは1ファイル=1学び**。書式: 状況 -> 誤り -> 正解 -> なぜ -> 出典(プロジェクト+ラウンド)。
- 各ファイルの先頭に**OKF互換のYAMLフロントマター**を付ける(必須は`type`。
  `title`/`description`/`tags`/`timestamp`/`source`も書く。**timestampは必ず**=
  「これは現代に通用するか」を時系列で振り返れるように)。
- **追記主義**: 過去の学びを書き換えない。誤りと分かった学びは、消すのではなく
  「誤りだった」という学びを重ねる。降格は`status: archived`のタグで(ファイルは動かさない)。
- **秘密を置かない**: 鍵・トークン・個人情報・非公開URLはどこにも書かない。
- 章立ての5セクション(`name`/`synopsis`/`description`/`history`/`seeAlso`)を
  ツール・スキル・PADで共通に使う。**道具は生まれた経緯(HISTORY)とセット**。
- チェックリスト・マトリックスの表はKoushi記法(```koushiフェンス)で書く。
- ブロックコメント内に終端2文字(アスタリスク+スラッシュ)を書かない(宙の辻で2回全壊した教訓)。

## してはいけないこと

- projects/以下を手で編集しない(あれは写し。正は各プロジェクト側にあり、sync.jsで上書きされる)。
- 双方向同期を作らない(正が2つになる)。
- 手書きの目次を作らない(index-genに任せる=腐らせない)。
