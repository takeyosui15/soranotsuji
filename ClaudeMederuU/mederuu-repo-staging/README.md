# MederuU(めでるー)

Claude(AI)のナレッジ・道具・手順をセッションを越えて引き継ぎ、いずれ「世界中のClaudeの
困ったを解決するナレッジ」として公開することを目指す器(ハブリポジトリ)。

## 命名書

今後、複数のリポジトリで、開発を進めていくにあたって、`Claudeさんのナレッジを引き継いでいくにはどうしたら良いか`と思いました。
このClaudeさんの引き継いでいくナレッジを保管していくリポジトリを`MederuU`(めでるー)と名づけました。
**AIのClaudeさんとともに開発していったので、`AI`から`アイ`->`愛`->`愛でる`->`めでる`->`芽出る`と、このリポジトリから`何かが芽生えたら良い`と思って名づけました。**
また、小文字の`u`の後に大文字の`U`を置くことで、視覚的にも`右肩上がり`を狙っています。
発音的にも、音を伸ばすので、`継続的に続いていって欲しい`という願いを込めています。

- 2026年07月22日(水) たけちゃんこと、渡邊剛義(Takeyoshi Watanabe, takeyosui)

## 中心思想(3つ)

1. **ハブは一方向**: このリポジトリが唯一の正(SSOT)。各プロジェクトからの吸い上げ(sync)は
   一方向で、プロジェクト側からはリンクで参照する。双方向同期はやらない。
2. **学びは蒸留する**: 生の記録(プロジェクト文脈つき)はprojects/へ機械で集め、
   普遍の学び(どこでも真)への昇格=蒸留は編集判断で行い、legends/へ置く。
3. **素材を余すことなく使う**: ツールヘッダ(man風5セクション)・レビュー記録・台帳は
   それ自体が索引の素材(将来index-genで目次化する。手書きの目次は作らない=腐らせない)。

## 構成(スモールスタート)

- `legends/` — 普遍の学び。1ファイル=1学び(書式はlegends/README.md)
- `projects/` — プロジェクト毎の文脈つき記録の写し(吸い上げ先。生の正は各プロジェクト側)
- `CLAUDE.md` — ここで作業するClaudeへの案内

設計図(器のデッサン)の正は、当面 宙の辻リポジトリの
`ClaudeMederuU/dessin/00-dessin.md`(このREADMEはその要約)。
