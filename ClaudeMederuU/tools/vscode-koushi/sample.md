## 2. 状態遷移表(結合セルxc/xr+罫線属性の例)

ヘッダは2段(イベントを結合セルでグループ化)。罫線属性は
「行に付ければその行の**上辺**・セルに付ければそのセルの**左辺**」で、
`bd`=二重・`bs`=太実線・`ba`=破線・`bo`=点線です。

```koushi
- t:1.
  - r:1:h.
    - c:1:xr2. 状態
    - c:2:xc2:bd. 検索系イベント
    - c:4:xc2:bd. 操作系イベント
  - r:2:h.
    - c:2:bd. 検索実行
    - c:3. フィルタ変更
    - c:4:bd. リセット
    - c:5. 閉じる
  - r:3:bs.
    - c:1. 結果なし
    - c:2:bd. 結果あり
    - c:3. -
    - c:4:bd. 結果なし
    - c:5. 結果なし
  - r:4:ba.
    - c:1. 結果あり
    - c:2:bd. 結果あり(再検索)
    - c:3. 結果あり(再導出)
    - c:4:bd. 結果なし
    - c:5. 結果あり(非表示)
```

## 4. input要素トークンの早見表(生きたサンプル)

数字(`c:1.`など)は**ただの目印**で、描画時は読み飛ばされます(振り直しても出力は同じ)。
22種の一覧はREADMEに、ここでは代表8種を実際に描画します。

```koushi
- t:1.
  - r:1:h.
    - c:1. トークン
    - c:2. 描画
    - c:3:bd. トークン
    - c:4. 描画
  - r:2.
    - c:1. chb:on.
    - c:2.
      - chb:on.
    - c:3:bd. rad:on.
    - c:4.
      - rad:on.
  - r:3.
    - c:1. btn:"実行".
    - c:2.
      - btn:"実行".
    - c:3:bd. txt:"名前を入力".
    - c:4.
      - txt:"名前を入力".
  - r:4.
    - c:1. dat:"2026-08-09".
    - c:2.
      - dat:"2026-08-09".
    - c:3:bd. nmb:"42".
    - c:4.
      - nmb:"42".
  - r:5.
    - c:1. rng:"50".
    - c:2.
      - rng:"50".
    - c:3:bd. clr:"#f0b429".
    - c:4.
      - clr:"#f0b429".
```
