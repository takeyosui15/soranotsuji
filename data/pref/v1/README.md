# data/pref/v1 — 都道府県の輪郭データ(pref-borders.json)

## これは何か
島リストの「都道府県」列など、緯度経度から都道府県を決めるための、47都道府県の輪郭(外形+県境)データです。
国土数値情報 行政区域データ(N03、2026-01-01版)の市区町村ポリゴンを都道府県単位に溶かし、
県境は元の解像度のまま、海岸線は間引いて、1本のJSON(約1.3 MB)にまとめています。

- ファイル: `pref-borders.json`(1,323,718 バイト、UTF-8、改行なし)
- 座標系: 経度・緯度(JGD2011、EPSG:6668)。1e-5度(約1 m)の整数に量子化
- 生成: `tools/pref/make-pref-borders.py`(再生成の手順は末尾)

## 作り方(要点)
1. 県ごとに N03 のGeoJSONを読み、全リングの辺を「2回出た辺は消える」集合(偶奇)で数える。
   市区町村どうしが接する辺は2回出て消え、残った辺がその県の輪郭になる(頂点は1e-7度の整数で突き合わせ)。
2. 県どうしで輪郭辺の共通部分をとる。共通の辺=県境(88組、302,164辺)。それ以外の輪郭辺=海岸線(と、所属未定地などの縁)。
3. 輪郭辺を鎖にして閉じたリングにし、相手県が同じ連続区間ごとに「アーク」に切る。
   県境アークは両県が同じ番号を共有し、元の解像度のまま(302,222点)。
   海岸線アークは Douglas-Peucker(許容 500 m)で間引く(7,959,521点 → 68,259点)。バッファ(膨らまし)はしていない。
   間引いた弦が他県の陸を横切ったり囲んだりしないように、近く(bbox+0.01度)にある他県の輪郭の頂点を格子に入れておき、
   「弦と元の海岸線で囲む領域」に他県の頂点が入る弦は最遠点で分けて作り直す(位相の保護。全国で61箇所。例: 因島(広島)の弦が生名島側(愛媛)の小島2つを飲んでいた)。
4. 海岸線だけでできた小さなリング(外接矩形の長辺が 50 m 未満。N03が持つ数mの岩礁など 111,509個)は落とす。
   県の判定には効かず、残すとファイルが約3.5 MB増えるため。50 m 以上の島はすべて残っている。
5. 座標を1e-5度の整数に量子化し、アークは差分符号化して書く。
   Google Encoded Polyline(文字列)と整数配列を両方作って小さい方を採用 → polyline が 1,064,665 バイト、整数配列が 2,130,432 バイトで polyline を採用。

集計: アーク 11,979本(県境 157本、海岸線 11,822本)、リング 11,727本、点 364,165個。
山岳一覧(1,063山)で検証すると 1,062山が記録どおりの都道府県に入り、外れた1山(鼻曲山)は県境から 1 m の地点にある。

## 限界(使う側が知っておくこと)
- 海岸線は 500 m までずれている。陸の点でも、海岸から 500 m 以内では「どの県にも入らない」ことがある。
  → 内外判定で入らなかった点は、海上かどうかにかかわらず**最寄り県**(下の使い方 4)で決める。
- 県の多角形どうしは重ならない(`tools/pref/verify-pref-borders.js` の overlap が 0 であることを確かめている)。
  ただし N03 の県境には、隣県どうしで頂点が1つ多い/少ない所があり、そこは共有辺にならず幅ゼロの「縫い目」(114本・計7.6 km・幅は最大6.4 m)として両県の海岸線アークに残る。
  複数の県に入る点が出た場合(本来は無い)は、自分の縁(海岸線・県境)が最も近い県にする(verify の `pip-tie`)。
- 外接矩形の長辺が 50 m 未満のリング(岩礁など 111,509個)は落としてある。その上の点は最寄り県で決まるので、狭い水道では隣県になることがある。
- 山岳一覧(1,063山)での正解率 99.9% は内陸の点の値。海岸・島の精度は上の2つの限界に従う。

## フォーマット
```jsonc
{
  "v": 1,
  "source": "国土数値情報 行政区域データ N03 2026-01-01版 (国土交通省) https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N03-2026.html (zip: https://...)",
  "retrieved": "2026-10-06",        // zipを取得した日
  "license": "CC BY 4.0 (国土数値情報ダウンロードサービス 利用規約)",
  "attribution": "「国土数値情報（行政区域データ）」（国土交通省）（https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N03-2026.html）を加工して作成",
  "attribution_short": "国土数値情報(行政区域データ)(国土交通省)を加工して作成",
  "generated": "2026-10-06",
  "tool": "tools/pref/make-pref-borders.py",
  "quant": 1e-5,                 // 座標の量子化単位(度)
  "coast_tolerance_m": 500,      // 海岸線の間引き許容(m)
  "min_ring_m": 50,              // 落とした小リングの閾値(m)
  "arcFormat": "polyline5",      // "polyline5" か "delta"
  "arcFormatNote": "...", "ringNote": "...", "topologyNote": "...",
  "stats": { "border_vertices": 302222, "coast_vertices_raw": 7959521, "coast_vertices_simplified": 68259,
             "arcs": 11979, "border_arcs": 157, "coast_arcs": 11822, "rings": 11727, "dropped_small_rings": 111509,
             "topology_splits": 61, "foreign_vertices": 4615400 },
  "arcs": [ "…polyline…", ... ], // アーク(点列)。番号は0始まり
  "prefs": [
    { "code": "01", "name": "北海道", "bbox": [w, s, e, n],   // 度
      "rings": [ [3, -5, 8], [9], ... ] },                     // 各リング = アーク番号の列
    ...
  ]
}
```
- `arcFormat: "polyline5"` のとき、各アークは Google Encoded Polyline(精度1e-5、緯度・経度の順、差分符号)の文字列。
  `"delta"` のときは `[x0, y0, dx1, dy1, ...]` の1e-5度整数配列(経度が先)。
- `rings` の各要素はアーク番号の列。負の値 `~i`(= `-i-1`)はアーク `i` を逆向きに辿る。
  隣り合うアークは端点を共有し、列の最後は最初の点に戻る(閉じたリング)。
- リングに「外側/穴」の区別はなく、県に属するか否かは **その県の全リングに対する偶奇規則**(交差回数が奇数なら内側)で決める。
  県境アークは隣り合う2県のリングに(逆向きで)現れる。

## 使い方
- 内外判定: 県の `bbox` で粗く絞り、リングの偶奇で判定する。全47県を順に試せばよい(1点あたり数μs)。
- どの県にも入らない点(海上の点、所属未定地、海岸から500 m以内の陸の点): 最寄りのアーク辺までの距離で「最寄り県」を決める。
  R木(アークの外接矩形)を使えば、日本のbbox内の乱数点5万個を約1.3秒で分類できる(Node 22、`tools/pref/verify-pref-borders.js` の計測)。
- 複数の県に入った点(本来は無い): 自分のアークが最も近い県にする。
- 復号・判定・最寄り県の参照実装: `tools/pref/verify-pref-borders.js`(`decodePolyline5`、`inPref`[リングの辺を緯度の帯に分けて速く]、`nearestArc`、`makeClassifier`)。`require` して使える。

## 再生成
```
python3 -I tools/pref/make-pref-borders.py --work /tmp/pref-borders      # 約6分、ピークのディスク使用量 < 1 GB
node tools/pref/verify-pref-borders.js                                     # 山岳一覧・重なり0・乱数点で指差し確認
node tools/pref/verify-pref-borders.js --probe "34.28937,133.17268"         # 任意の点の県を見る
```
詳細は `tools/pref/README.md`。
