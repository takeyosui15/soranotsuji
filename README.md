# [宙の辻 - Sora no Tsuji](https://soranotsuji.net/)

**山 × 天の川 × 太陽 × 月。「山頂と天体が重なる瞬間」の時間と場所を、地図から逆算する。**

「宙の辻 - Sora no Tsuji」は、天体シミュレーションと地図情報を組み合わせたWebアプリケーションです。
特定の日時・場所における天の川、太陽、月、惑星、恒星の位置を計算し、天の川富士・ダイヤモンド富士・パール富士・ダイヤモンド槍ヶ岳・パール槍ヶ岳など、お好みの山『推し山』と天体が重なって見える時間と場所の「辻（交差点）」をマップ上に可視化します。
ブラウザだけで動作します（スマホ/PC・インストール不要・無料）。

## 道具は4つ

ほかの機能は、すべてこの4つの補助です。

* **辻ライン**: いま設定している日時に「山頂と天体が重なって見える場所」を、地図に線で描画。実線=天体の中心が完全に重なる位置（5分刻みの時刻マーカー付き）、破線・鎖線=精度◎○△の境界、点線=前日・翌日。
* **辻検索**: 立つ場所（観測点）から目的点の方向に天体が重なる日時を、1日1件でリストアップ。重なりの近さは精度記号（◎=±0.125°・○=±0.25°・△=±1°・-=許容範囲内）で表示。
* **辻メッシュ検索**: 逆に「どこに立てば重なる日があるか」を、観測点付近の標高メッシュ全画素（約10m四方）を観測点とみなして検索し、地図の面で表示。
* **宙の窓**: その瞬間の見え方を、カメラのファインダーそのままにプレビュー。国土地理院の標高データによる山並みと天体を実距離・実寸で描画。

## 主な機能

* **オフセット検索**: 「山頂の右斜め上に満月」のようなズレ量つきの構図を、方位角/視高度・目的点での距離換算・観測点での回転角の3通りで指定して検索。検索中心は「点」と「基準点からの線」を選択可能。
* **フィルタ**: 月齢（満月・新月など）・精度記号・時刻（日の出入りや薄明基準）・曜日・月・標高（目的点が見通せる場所だけ）で検索結果を絞り込み。
* **辻ライン365**: 向こう365日の辻ラインを重ね描き。推し山ダイヤ/パールの場所の範囲が一目で分かる。
* **可視判定**: 観測点→目的点の見通しを、地球の丸み（WGS84回転楕円体の局所半径）と大気差（気象値連動）を考慮して判定。標高グラフの断面表示・辻検索/辻メッシュ検索の標高フィルタで共通。
* **宙の窓の発展機能**: センサー・焦点距離（1〜3000mm）・F値による実画角、魚眼・円筒パノラマ、天体の軌跡（±36時間・大気差込み）、静止画/タイムラプス動画の書き出し、花火モード、都市モード（国土交通省PLATEAUの実寸3D都市モデル・約300市区町村）、写真テクスチャ（国土地理院の全国最新写真を山肌にドレープ）、観測点の1m単位の移動/回転ボタン。
* **天体儀**: 天球を丸ごと外から眺められる3D天体儀。天の川の環・表示天体の軌跡・星座線・星座領域・星座名称を表示。
* **表示天体 / 天体検索 / My天体**: 太陽・月・惑星（冥王星まで）・主要恒星・天の川を標準搭載。天体データベース検索から最大1000件まで追加登録。
* **My観測点 / My目的点 / My辻検索 / Myセット**: よく使う場所と検索条件の登録・一括計算・CSV入出力。セット単位の切り替えと、Googleスプレッドシートへの保存/読込・共有に対応。
* **共有**: 現在の画面を再現するURL（用途別の絞り込み発行）・辞書圧縮の短縮URL・QRコード。Googleアカウントによる全設定の端末間共有（Googleドライブ）と、ファイルへの一括バックアップ/インポート。
* **入力の小道具**: GPS・地名検索・「緯度,経度」・Google Plus Code（フル/短縮形）による位置入力、Hom/推し山の登録呼出、高移（最寄りの小ピークへ）、日時ショートカット（Now・日の出入り・月齢ジャンプ・薄明・アニメーション再生）。
* **海外対応**: 日本国外の地点・タイムゾーンでも利用可能（標高は全球DEMへ自動切替・地名検索はOSM）。

詳しい使い方は、アプリ内のヘルプ（メニュー最上部の[?]アイコン）と[紹介ページ（note）](https://note.com/takeyosui)をご覧ください。

## 使い方（最短の3手順）

**場面A: 立つ場所も撮りたい山も決まっている → 辻検索**

1. 地図をクリック（または地名・「緯度,経度」・Google Plus Code）で観測点と目的点を設定（標高は自動入力。初期値: 東京タワー→富士山）。
2. 「辻検索」ボタンで、重なる日時をリストアップ。
3. 結果の行をタップして「宙の窓」でその瞬間の構図をプレビュー。

**場面B: 撮りたい山だけ決まっている → 辻メッシュ検索**

1. 目的点に撮りたい山を設定（観測点はだいたいの位置でOK）。
2. 「辻メッシュ」ボタンで、重なる日がある場所が金色のマーカーの面で表示。
3. マーカーをタップして日時一覧→宙の窓でプレビュー。

## 使用技術

* **HTML5 / CSS3 / JavaScript (Vanilla)**
* **[MapLibre GL JS](https://maplibre.org/)**: 地図表示エンジン
* **[Astronomy Engine](https://github.com/cosinekitty/astronomy)**: 天体位置計算エンジン
* **[Three.js](https://threejs.org/)**: 3D描画（宙の窓・天体儀）
* **[GeographicLib](https://geographiclib.sourceforge.io/)**: 測地線および DMS ルーチン
* **[qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator)**: QRコード生成
* **国土地理院（地理院タイル）**: 地図・標高タイル・全国最新写真（シームレス）・標高/地名API
* **OpenStreetMap (Nominatim)**: 地図タイル・地名検索
* **国土交通省 Project PLATEAU**: 3D都市モデル（建築物モデル・CC BY 4.0）。メッシュ展開に [Google Draco](https://github.com/google/draco)
* **NASA Scientific Visualization Studio**: 天の川・星座画像（Deep Star Maps 2020）
* **Terrain Tiles (Mapzen/AWS)**: 日本域外の全球標高データ
* **Open-Meteo**: 気象データ
* **d3-celestial**: 星座線・星座境界データ（IAU・BSD-3）
* **Google Drive / Sheets API**: 設定の端末間共有・Myセットのスプレッドシート連携
