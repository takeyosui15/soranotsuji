# 宙の辻 v1.86.0 リリースのお知らせ

宙の辻 v1.86.0 をリリースしました。本バージョンは、可視判定 (見通し判定) の精度向上と、宙の窓の新オプション「写真テクスチャ」の追加が柱です。
可視判定は、遠距離ではこれまでと結果が変わることがあります。あわせてご覧ください。

## 1. 可視判定が地球の丸みと大気差を考慮するようになりました

観測点から目的点が見通せるかどうかの判定 (標高グラフの可視判定と、辻検索・辻メッシュ検索の標高フィルタ) を、地球の丸みと大気差を考慮した計算に改めました。

- これまでは、観測点と目的点を直線で結び、途中の地形と比べていました。地球の丸みを考慮していないため、遠距離では実際には見えない目的点を「OK」と判定することがありました。
- これからは、地球の丸み (回転楕円体の局所半径) に、大気差による光の屈折 (見通し距離が伸びる効果) を加味した実効半径で判定します。大気差は「:大気差」設定と気象値 (気圧・気温・気温減率) に連動し、宙の窓の地形描画と同じ扱いです。

この変更により、遠距離の組み合わせでは、これまで「OK」だった判定が「NG」に変わることがあります。
たとえば約150km先の山を望む場合、途中の約60km地点にある稜線が、直線ではわずかに下を通っていても、丸みを考慮すると見通し線より高くなり、正しく「NG」になります。
実際の見え方に合った判定への変更ですので、ご了承ください (宙の窓の描画は従来から丸みと大気差を考慮しており、判定と見え方が一致するようになりました)。

## 2. 標高グラフの見通し線が曲線になりました

標高グラフの見通し線 (観測点と目的点を結ぶ赤い線) を、地球の丸みによる沈み込みを反映した曲線で表示するようにしました。
可視判定と同じ計算のため、グラフ上で線が地形と交わる位置が、そのまま判定結果と一致します。
判定結果のポップアップにも、丸みと大気差を考慮している旨の注記を添えました。

## 3. 宙の窓「:写真テクスチャ」(新機能)

宙の窓の山肌に、国土地理院の「全国最新写真 (シームレス)」を貼り付けるオプションを追加しました。

- 山並みの色や雪渓・森林の様子が航空写真の色で表示され、遠くの山の見え方がより実際に近づきます。
- 地形の頂点単位の彩色のため、近景はぼかし気味の表示になります。遠景の山並みの確認に向いています。
- 太陽光ヒルシェードと重ねて使えます (陰影が写真の色に乗ります)。
- 対象は日本国内の地形です (国外の地形はこれまでどおりの色で表示されます)。
- オンにすると地形データを取得し直すため、表示に少し時間がかかります。

## 4. 不具合対策

- 宙の窓の天体の軌跡が大気差を考慮しておらず、地平線の近くで天体マーカーと軌跡の位置がわずかにずれることがありました。軌跡にもマーカーと同じ大気差を反映し、ずれを解消しました。

## 5. その他の改善

- 全天儀の天体の軌跡の線を太くしました。細い線で見づらかった軌跡が、スマートフォンでも読み取りやすくなります。
