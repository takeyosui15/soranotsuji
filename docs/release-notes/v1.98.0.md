# 宙の辻 v1.98.0 リリースのお知らせ

宙の辻 v1.98.0 をリリースしました。前回 (v1.87.0) からの変更をまとめてお届けします。主な内容は、「宙の窓検索」、地図と標高タイルの端末への控え (電波の無い所でも使える)、気差 (大気差) の扱いの見直し、可視判定の統一と除外範囲「山頂部」、辻ラインの範囲拡大、そしてセキュリティの強化です。

※ 更新後、大気差の設定が一度だけ「オン」に切り替わり、辻検索や可視判定の結果が変わることがあります (3. をご覧ください)。
※ 開発中の機能 (可視マップ) は、今回のリリースには含まれていません。
※ 宙の窓検索とオフライン表示は、セキュリティ対策を急いだため、今後、機能が改善予定です。

## 1. 新機能: 宙の窓検索 (構図を見ながら辻オフセット点を決める)

位置情報メニューの「宙の窓」ボタンが「**宙の窓検索**」になりました。観測点から目的点を見た構図 (ファインダー) を描き、辻検索で天体を重ねる点=辻オフセット点 (目的点からのずれを辻オフセット方位角/視高度で指定するもの。プレビューでは検索の中心を示す×印) を構図を見ながら決めて、そのまま辻検索・辻メッシュ検索へ進めます。

- 宙の窓のコントロールに「**:構図をドラッグ (二本指) で変更**」と「**:辻オフセット点をドラッグ (二本指) で変更**」のチェックを追加しました (PCはマウスのドラッグ、スマホは二本指のドラッグ)。ドラッグで動かす対象を、カメラの向き (構図) と辻オフセット点のどちらにするかを選べます (オフにすると元に戻ります)。
- 同じコントロールに「**辻検索**」「**辻メッシュ**」ボタンを置きました。構図の上で決めた辻オフセット点 (検索の中心を示す×) は辻検索・辻メッシュ検索のオフセットに写り、「辻メッシュ」はその×の位置を中心に検索します。
- 「山頂の右斜め上に月」のような構図を、数値ではなく絵の上で決められます。

## 2. 地図と標高タイルを端末に控える (電波の無い所でも)

地図に使う国土地理院のタイル (標準・淡色・写真・ベクトル) と、標高グラフ・辻検索・辻メッシュ検索・宙の窓が使う標高タイルは、一度読んだものをブラウザの中に控え、次からは控えを先に読み、無いものだけ国土地理院へ取りに行くようにしました。

- 控えのある範囲は、電波の無い所でも地図と計算が使えます。山の上や谷の中で、麓で見ておいた範囲を開き直す、という使い方ができます (アプリのページ自体を開くには通信が必要です。開いたまま圏外になった時に効きます)。
- 控えはこの端末の中だけにあり、どこにも送られません。
- バックアップメニューに、地理タイル / 標高タイルそれぞれの件数・容量・最終更新日時を表示し、「全削除」でいつでも空にできます (次に表示した時にまた取りに行くだけです)。地理タイルの控えは合計1GBまでで、それを超えると新しくは貯めません。
- データリセットのページ (reset.html) の「すべてのデータを消去する」でも、これらの控えは消去されます。

## 3. 気差 (大気差) の扱いを見直し: 2つのスイッチに

遠くの景色を見たときに光が空気の層で曲がる効果 (気差) の扱いを、「地形の見通し」と「天体の見かけ高度」の2つに分けました。

- **設定の「気差係数 K」の先頭のチェック (大気差補正)** = 地形の見通しに使う気差係数 K。オン (既定。これまでの初期値はオフでした) のときは気象条件から算出した値 (標準の気象条件で K=0.132)、オフのときは K=0 (気差なし=地球の丸みだけ。K=0 の見え方を確かめるためのスイッチです)。係数欄に表示されている値で、標高グラフ・辻検索・My辻検索・辻メッシュ検索・辻ライン・宙の窓の全てが同じ1つの値で計算します。
- 新しい「**:気差オプション (Astronomy Engine気差補正)**」= 天体の見かけ高度の大気差 (地平線近くで天体が浮き上がって見える効果。既定オン)。辻検索・辻メッシュ検索・My辻検索・辻ライン・宙の窓の天体の見かけ高度と、天体リストの高度・恒星 (My天体) の出没時刻・日の出入り/月の出入りの高度に効きます (太陽・月・惑星の出没時刻そのものと、天体儀の向きは変わりません)。地上の K とは別の光の曲がりなので、両方オンでも二重にはかかりません。共有URLにも載ります。
- 気温減率 Γ の既定値を 0.0065 から **0.0125** に変えました (測量で標準的に使われる K=0.132 になる値です)。保存済みの設定が旧既定のままだった場合は、新しい既定に一度だけ切り替わります (ご自身で変えた値はそのままです)。
- **結果が変わることがあります**: これまでは1つのチェック (初期値オフ) が、地形の見通しの気差と天体の大気差の両方を兼ねていました。今回これを2つに分け、既定を両方オンにしました。更新後は、保存済みの設定も一度だけ両方オンに切り替わります (以前オフにしていた方も含みます)。このため、これまでオフ (初期値) で使っていた方は、可視判定が K=0 から気象条件の値 (標準で K=0.132) に変わり、辻検索・辻ラインなどの天体の見かけ高度にも大気差が入るので、辻時刻や可視の結果が変わることがあります。オンで使っていた方も、気象条件を既定のままにしていた場合は K が約0.169から0.132に変わります。従来どおりの計算に戻すには、設定メニューで「気差係数 K」の先頭のチェックと「:気差オプション」の両方をオフにしてください (K=0・幾何学的な高度)。

## 4. 可視判定 (可視フィルタ) の統一と、除外範囲「山頂部」

辻検索・辻メッシュ検索・My辻検索の「標高フィルタ」を「**可視フィルタ**」に改名しました (表示の名前だけで、My辻リストのCSVの列名は互換のためそのままです)。

- 標高グラフ・辻検索・辻メッシュ検索の可視判定を、同じ3つの規則にそろえました: 経路を大円 (球面上の最短経路) でたどる・海 (日本付近で標高データの無い所) は海面0mの遮るものとして扱う・気差係数は設定の値。これまでと結果が変わる場所があります。気になる場所は、標高グラフで OK/NG と見通し線 (赤線) を確かめてください。
- 基本オプション > 標高グラフ > 除外範囲に「**:山頂部**」(初期値オン・帯の高さ300m) を追加しました。目的点の標高から帯の高さ以内で目的点につながる範囲 (探索半径3km) の地形を、遮るものに数えません。火口の縁や山頂直下の斜面が目的点そのものを隠す誤判定 (富士山を北から見ると剣ヶ峯が北側の縁に隠れる、など) を防ぎます。
- 帯の高さ「山頂部 (帯,m)」は山ごとに変えられ (120=火口の縁まで・300=山頂の肩まで・500=山頂直下の斜面まで、が目安)、「**:プレビュー**」でその範囲を地図に薄い赤で描いて確かめられます。「除外範囲をリセット」で初期値に戻ります。
- 初期値の富士山のように、目的点が火口の中心にあって、標高データ (火口の底) より目的点の標高 (剣ヶ峯の3776m) が高いときは、目的点の標高を基準に山頂部を決めます。山頂部に別の山の山頂が入るときは、入らない高さまで自動で縮めます。目的点が山頂でないとき (山腹や谷) は山頂部は使わず、これまでどおりの判定です。

## 5. 辻ライン: 線の範囲を 400km に

辻ラインの範囲を目的点から 300km 以内から **400km 以内**に広げました (富士山が見えた最遠の記録が300km台にあるためです)。線の端は、目的点が見かけの地平線に沈む高度か 400km のどちらか近い方です。

## 6. セキュリティの強化

2026年10月に国内で不正アクセスの被害が相次いだことを受けて、宙の辻の作りを点検し、守りを強めました。宙の辻で不正アクセスや情報の流出が起きたわけではなく、予防のための点検です。利用者の方にしていただくことはありません (更新後もログインや設定はそのままお使いいただけます)。宙の辻は「サーバーに利用者のデータを預からない」作り (データは端末の中と、ご自身の Google ドライブ / スプレッドシートだけ) で、それは変わりません。

- **ライブラリの自前配信**: これまで外部の配信網 (CDN) から読み込んでいた地図・天体計算・3D描画などのライブラリを、宙の辻のサイト自身から配信するようにしました。配信元の改ざんや停止の影響を受けず、中身は台帳 (版と指紋) で管理しています。
- **読み込み元の許可リスト**: ブラウザに「このページが通信してよい先」(宙の辻のサイト・国土地理院・Open-Meteo・OpenStreetMap・Google など、使っている先だけ) を宣言し、それ以外とは通信しないようにしました。ページの中に書かれたスクリプトは禁じ、宙の辻のファイルと Google のログイン・ピッカー用のスクリプトだけが動きます。
- **取り込むデータの検査**: バックアップファイルや共有シート、共有URLから取り込むデータの型 (数値・文字・色) を検査し、文字として扱うようにしました。細工されたファイルを読み込んでも、その中身がプログラムとして動かないようにしました。CSVの出力では、表計算ソフトが式として解釈しうる先頭文字を無害化します。
- **Google 連携の点検**: 宙の辻が求める許可は「宙の辻で作った / 選んだファイルだけ」の最小のまま。ログインの鍵 (アクセストークン) は端末の中にも保存せず、ログアウトで Google 側の許可も取り消します。Google Cloud 側の設定 (APIキーの利用サイトの制限・許可の範囲・同意画面) も点検しました。
- **配信元の守り**: 公開リポジトリの配信元ブランチの保護、秘密情報の誤った公開を止める仕組み、開発者アカウントの2段階認証を整えました。

## 7. その他の修正
