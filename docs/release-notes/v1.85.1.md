# 宙の辻 v1.85.1 リリースのお知らせ

宙の辻 v1.85.1 をリリースしました。本バージョンは、共有URLの不具合修正です。
v1.85.0でURLを共有してくださった皆さまに、お手数をおかけするお願いがあります。あわせてご覧ください。

## 不具合の内容

位置情報メニューの「URL」ボタンで取得したURLに、以下の設定が含まれていませんでした。

- 辻検索・辻メッシュ検索の検索条件 (基準方位角・オフセット・許容量・検索期間・各フィルタなど)
- 天体の色・線種のうち、初期設定のままの項目
- 宙の窓の一部の表示設定 (白黒表示・注記の文字サイズ・都市の建物表示の切り替え)

このため、共有されたURLを開いたときに、次の現象が起きていました。

- 検索条件が、URLを作成した方の設定ではなく、開いた方の端末の設定 (または初期設定) で表示される。
- 同じURLを2回目以降に開いたときに、1回目に開いた際に変更した設定が残ったまま表示される。

## 修正の内容

- 位置情報メニューのURLに、上記の設定をすべて含めるようにしました。
- URLに含まれる設定は開くたびに毎回適用され、同じURLは何度開いても同じ画面で開きます。
- 検索結果を表示した状態で取得したURLは、開いた側でも同じ条件で検索が自動実行され、同じ結果が表示されます。
- URLを開いても、開いた方の端末に保存されている設定は変わりません (従来どおりです)。

## お願い: 共有中のURLの取り直しについて

v1.85.1より前に位置情報メニューで取得したURLには、この修正を適用できません (URLの内容は取得した時点で固定されるため)。
共有中のURLがある場合は、お手数ですが、v1.85.1で取得し直したURLへの差し替えをお願いいたします。

- 取り直しをお願いしたいURL: 位置情報メニューの「URL」ボタンで取得したもの (天体の色を変更して共有した宙の窓のURLも対象です)。
- 取り直し不要のURL: 辻検索・辻メッシュ検索の「URL」ボタンで取得したもの (検索条件は従来から含まれています)。

なお、以前のURLも引き続き開くことができ、観測点・日時・画面設定はこれまでどおり再現されます。
