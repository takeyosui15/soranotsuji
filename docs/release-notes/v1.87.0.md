# 宙の辻 v1.87.0 リリースのお知らせ

宙の辻 v1.87.0 をリリースしました。本バージョンは、設定の端末間共有 (Googleドライブ同期) の新オプション「自動更新」、写真の位置情報からのMy観測点/My目的点の追加、および同期表示の不具合修正です。

## 1. 不具合修正: 同期ダイアログの「New」マークが両方に付くことがある

端末 (ローカル) とGoogleドライブそれぞれの更新日時に付く「New」マークが、両方に付くことがある不具合を修正しました。

- **不具合の内容**: 「New」マークは、前回の同期からその側に変更があったかどうかを、端末側とドライブ側で別々に表示していました。このため、両方に変更がある場合や、この端末でまだ一度も同期していない場合に、両方へ「New」が付いて、どちらを残せば良いか分からない表示になっていました。
- **修正の内容**: 「New」マークは、常に**どちらか一方だけ**に付くようにしました。片方だけに変更がある場合はその側に、両方に変更がある場合は、更新日時 (日付ではなく秒までの日時) を比較して新しい側に付きます。
- **影響範囲**: 変わるのはダイアログの「New」マークの付き方だけです。同期状態アイコン (👍/👎) の判定や、保存・読み込みの動作に変更はありません。

## 2. 新機能: 「:自動更新」(Googleドライブへの自動保存)

同期状態アイコンを押したときのダイアログの一番下に、「**:自動更新**」チェックボックスを追加しました (初期値オフ)。

- オンにすると、端末の内容に変更があったとき、少し待ってから (最後の変更から約30秒後にまとめて1回) Googleドライブへ自動で保存します。画面を閉じたり裏に回したりしたときにも、待たずに1回保存します。
- **他の端末の変更は消しません**: 自動保存の直前にGoogleドライブ側の更新を確認し、他の端末が先に保存していた場合は自動では上書きせず、同期状態を👎に戻してダイアログでの選択 (保存/読み込み) に委ねます。
- ログインが切れているときは自動保存を止め、アイコンが🈚️になります (ログインし直すと👎から手動で同期できます)。通信に失敗したときは次の機会に持ち越します。いずれの場合も、変更した内容は端末に残ります。
- 「開いたらまず同期、あとはおまかせ」という使い方ができ、複数端末での共有がより安全・手軽になります。

## 3. 辻メッシュ検索: 精度フィルタに「○」を追加 (初期値)

辻メッシュ検索の精度フィルタオプションに「**:○**」(±0.25°) を追加し、初期値にしました。

- 選択肢は「:○」「:◎」「:◎×2」「:◎×4」の4つになります (「:◎×8」は選択肢から外れました。保存済みの◎×8は◎×4として引き継がれます)。
- ◎だけではピンポイント過ぎて使いづらい場面があり、辻検索で普段使う「◎と○」の実用的な範囲に合わせた変更です。○で検索すると、該当する場所 (金色のマーカー) がより広く見つかります。
- 辻時刻スライダーの精度フィルタオプションのリストにも「○(±0.25°)」を追加し、こちらも初期値を「○」にしました。検索を「○」で行って全ての精度のデータを持っておき、スライダー側のリストで表示を絞り込む、という同じ考え方で使えます。

## 4. 宙の窓: カメラオフセットのリセット

宙の窓ボタンで開き直すたびに、カメラオフセット方位角/視高度が0にリセットされるようにしました。

- これまでは前回のズレた状態が保存されていて、開くたびにズレたまま表示されていました。
- 共有URLから宙の窓が自動で開く場合は、URLに含まれる構図 (オフセット込み) をそのまま再現します。

## 5. 新機能: My観測点 / My目的点の「写真から追加」

My観測点・My目的点のメニューに「**写真から追加**」ボタンを追加しました。撮った写真の位置情報 (Exif) から、観測点・目的点を登録できます。

- ボタンを押して写真を選ぶと、写真の位置情報から緯度経度を読み取り、確認の上で行を追加します。観測点名/目的点名は「新規観測点名/新規目的点名」、標高は緯度経度から取得し直し、高さは0で入るので、そのまま「全て登録」できます。
- **写真はどこにも送信・保存されません**。位置情報の読み取りは利用者の端末内 (ブラウザ内) だけで行います (プライバシーポリシーにも明記しました)。
- 位置情報 (Exif) 付きのJPEG写真に対応しています。スクリーンショットや、SNS・メッセージアプリを経由した画像は位置情報が取り除かれていることが多く、その場合は追加できません。
- 「あの時撮ったこの場所から、また狙いたい」を、写真から直接登録できるようになります。

## 6. ヘルプ: 宙の辻フォルダは名前変更・移動しても大丈夫です

Googleドライブ上の保存先 (宙の辻フォルダ) は、名前ではなくフォルダに付けた目印で追跡しているため、ドライブ側で**名前変更・移動をしても連携はそのまま保たれます**。ご自身のドライブの整理に合わせて自由に動かせます。この説明をヘルプに追記しました。
