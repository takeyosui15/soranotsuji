# 宙の辻 v1.86.1 リリースのお知らせ

宙の辻 v1.86.1 をリリースしました。本バージョンは、v1.86.0で見つかった不具合の修正と、機能名の修正です。

## 1. 不具合修正: 天体儀の天の川オフセット点の位置

天体儀 (3D天体儀パネル) で、天の川のオフセット中心角を変更したときに、中心からオフセット点へ引かれる方位線とマーカーの位置が、天の川の軌跡の線とズレる不具合を修正しました。

- **不具合の内容**: 天体儀のオフセット点のマーカーと方位線だけが、オフセット中心角と逆回りの位置に表示されていました (例: +30°を指定すると-30°の位置に表示)。このため、正しい位置に描かれている軌跡の線と、角度の2倍ぶんズレて見えていました。
- **修正の内容**: オフセット点の位置計算を、辻検索・辻メッシュ検索・辻ライン・My辻検索・天体の軌跡が使っている共通の計算に一本化しました。オフセット中心角の向きは、従来どおり「夏の天の川を上から見て時計回りが正」です。
- **影響範囲**: ズレていたのは天体儀のオフセット点の表示だけです。辻検索・辻メッシュ検索・辻ライン・My辻検索の計算は元から正しく、検索結果や共有URLへの影響はありません。

## 2. 機能名の修正: 「全天儀」→「天体儀」

天球を外から眺める3Dパネルの名称を、「全天儀」から「**天体儀**」に修正しました。
ボタン・メニュー・ヘルプなど、アプリ内の表記をすべて新しい名称に揃えています。機能の内容や操作に変更はありません。
