# 宙の辻 v1.85.0 リリースのお知らせ

宙の辻 v1.85.0 をリリースしました。本バージョンは、構図シミュレーションの「宙の窓」、3D天体儀の「全天儀」、面で探す「辻メッシュ検索」、リストをまとめて切り替える「Myセット」、設定の端末間共有を新たに搭載し、辻検索も大幅に強化した、これまでで最大のアップデートです。

## 1. 宙の窓 (新機能)

カメラを構えたときの見え方を、そのままシミュレーションするプレビュー機能です。

- **カメラ設定**: センサーサイズ・アスペクト比・縦横の構え・焦点距離 (1〜3000mm)・F値・フォーカス距離を指定でき、実際のレンズの画角で表示します。魚眼 (強さ・形状) と円筒パノラマにも対応しています。
- **地形と天体を実寸配置**: 国土地理院の標高データによる山並みと、太陽・月・惑星・恒星・天の川 (NASAの全天写真) を実距離・実寸で描画します。山の稜線に沈む月や、稜線から昇る天の川の位置関係が構図どおりに確認できます。大気差も反映します。
- **表示オプション**: 天体の軌跡 (±36時間)・中央十字・目的点十字・検索中心マーク・天の川の明るさ・地形の陰影・太陽方向の陰影を調整できます。
- **日時の操作**: 日の出入り・月の出入り・薄明へのジャンプ、月齢移動、時刻スライダー、アニメーション再生など、日時情報メニューの操作一式をコントロールメニューにそのまま収録しました。
- **観測点の微調整**: 観測点を1m単位で動かす移動ボタン (向きの回転付き) と、カメラの向きを1°単位で振るボタンを用意しました。見え方だけを先に動かして、良い構図が見つかったら「位置反映」で観測点を確定できます。
- **インターバル再生と書き出し**: 指定間隔・枚数のインターバル再生 (アニメーション/動画) と、WebM/H.264動画・JPEG/PNG連番の書き出しができます。
- **花火モード**: 打ち上げ花火のシミュレーションです。号数 (2.5〜40号)・色々/固定・頻度・ばらつき・打ち上げ点と領域を指定できます。実寸配置のため、手前の山に隠れる花火もそのとおりに写ります。
- **都市モード**: 国土交通省Project PLATEAUの3D都市モデルで、都市部のビル群を実寸表示します (整備済みの約300市区町村)。航空写真テクスチャ・表示タイル数・整備年度の表示に対応し、夜はビルに窓明かりが灯ります。

## 2. 全天儀 (新機能)

天球を丸ごと外から眺められる、3Dの天体儀です。

- ドラッグで自由に回せます。回転方向の固定 (水平/地軸/自由) と、「北奥」「目的点前」への向きリセットを用意しました。
- 前景/後景/透過の切り替えで、天球の内側と外側のどちらからでも眺められます。
- 表示天体の軌跡と天体名、星座線・星座領域・星座名称 (50音順/座標順) を表示できます。
- 天の川の環・中心・オフセット点も表示され、日時情報メニューと完全に連動します。コントロールメニューには宙の窓と同じ日時操作一式を収録しています。

## 3. 辻メッシュ検索 (新機能)

「どこに立てば撮れるか」を、点ではなく面で探す検索です。

- 観測点付近の標高メッシュの全画素 (約10m四方) をそれぞれ観測点とみなして辻検索し、高精度の日時が存在する場所を地図上に面で表示します。
- 精度は◎ (±0.125°) から◎×128 (約±0.001°) までの8段階で指定できます。
- ヒット件数は色のグラデーションで表示され、最多ヒットの画素は金と赤の縞模様で一目で分かります。
- 辻時刻スライダーを動かすと、その瞬間に辻が成立する画素をライブで再計算し、最良の画素には金色の「優辻マーカー」が立ちます。
- 画素をクリックすると「そこに立ったときの辻」へ観測点・日時・辻ラインがまとめて移動します。
- 標高フィルタを使うと、目的点が見通せる画素 (OK) / 見通せない画素 (NG) だけに絞って検索できます。

## 4. Myセット (新機能)

My辻検索・My観測点・My目的点・My天体の組を「セット」として複数管理し、まとめて切り替えられます。

- 撮影テーマや遠征先ごとにセットを作り、ワンタップで切り替えられます。
- セットごとにGoogleスプレッドシートへ紐付けて保存/読込ができます。中身は普通のスプレッドシートなので、そのまま閲覧・編集・シート追加・共有も可能です。
- お気に入り⭐️で よく使うセットを上位に表示し、セット名とメモによる絞り込みもできます。

## 5. 設定の端末間共有 (新機能)

- Googleアカウントにログインすると、アプリの全設定をGoogleドライブに保存し、PCとスマホなど複数の端末で共有できます。
- 端末とドライブに差分があるときは、どちらを使うかをダイアログで選べます。同期状態はヘッダのアイコンで一目で分かります。
- 従来どおり、ファイルによるローカルのバックアップ/インポートも利用できます。

## 6. 以前の辻検索からのアップデート

- **検索中心のオフセット**: 辻オフセット方位角/視高度で、検索中心を基準点 (目的点の方向) から任意にずらせるようになりました (目的点基準の距離表示付き)。検索中心は「点」と「基準点からの線」から選べ、辻ライン・辻ライン365にも反映されます。
- **フィルタの拡充**: 月齢・精度記号・時刻 (日の出入りや薄明を基準にした範囲指定)・曜日・月・標高 (目的点の見通しOK/NG) で結果を絞り込めます。
- **結果の強化**: 検索結果の絞り込みコントロール、CSVファイル出力、検索記録からの再現に対応しました。
- **天の川のオフセット中心角**: 天の川の環の任意の位置を狙えるようになりました (夏の天の川を上から見て時計回りが正)。
- **入力の強化**: 地名・住所検索に加えて、GoogleマップのPlus Code (フルコード/短縮形) で位置を入力できます。海外のタイムゾーンにも対応しました。
- **共有URLの刷新**: URL取得ボタンごとに目的に合った内容のURLを発行します (位置情報=画面の完全再現/辻検索・辻メッシュ検索=検索の再現/宙の窓=窓の再現/My項目=その項目のみ)。圧縮した短いURLと、QRコード画像のコピーにも対応しました。

## 7. 不具合対策

- 表示天体で月を選択した場合の辻ラインで、日付を跨ぐ辻ラインの描画に不具合がありました。日付を超えたラインが描画されないという不具合を修正しました。月のように南中時刻が毎日約50分ずれる天体でも、0時を跨ぐ辻ラインが正しく描画されます。

## ご利用にあたっての補足

- 都市モードのビルのテクスチャは、PLATEAUの整備範囲の建物にのみ用意されています。テクスチャのないビルは単色+陰影で表示されます (整備の拡大に合わせて順次広がる見込みです)。
- 都市モードの表示タイル数は、スマートフォンでは控えめな値でのご利用をおすすめします。
- 辻ライン365は計算量が大きいため、起動時は常にOFFで始まります。
