> ## 3. 気差 (大気差) の扱いを見直し: 2つのスイッチに
>
> 遠くの景色を見たときに光が空気の層で曲がる効果 (気差) の扱いを、「地形の見通し」と「天体の見かけ高度」の2つに分けました。

> - **設定の「気差係数 K」の先頭のチェック (大気差補正)** = 地形の見通しに使う気差係数 K。オン (既定。これまでの初期値はオフでした) のときは気象条件から算出した値 (標準の気象条件で K=0.132)、オフのときは K=0 (気差なし=地球の丸みだけ。K=0 の見え方を確かめるためのスイッチです)。係数欄に表示されている値で、標高グラフ・辻検索・My辻検索・辻メッシュ検索・辻ライン・宙の窓の全てが同じ1つの値で計算します。

> #### 1. 言葉の意味(ここが分かれば、あとは見るだけです)
>
> - **Watch(ウォッチ)** = 「そのリポジトリの動き(Issue・プルリクエスト・セキュリティの知らせなど)を、自分に通知してもらう」設定です。日本語の「見張る」に近い言葉ですが、GitHub では「通知を受ける」の意味で、**自分のリポジトリにも使います**(自分のリポジトリで起きたことを自分に知らせてもらう)。他人のリポジトリ専用ではありません。
> - **ボタンの表示は「今の状態」ではなく「押したら何が起きるか」**です:
>   - 通知を受けて**いない**時 → ボタンは「**Watch**」(押すと受け始める)。
>   - 通知を受けて**いる**時 → ボタンは「**Unwatch**」(押すと止める)。
>   - なので、**「Unwatch」と出ていれば「今は通知を受けている」=よい状態**です。前回「Unwatch になっていれば大丈夫」と書いたのは、この意味でした(言葉だけ見ると「解除」に見えるので、分かりにくかったと思います)。
> - ボタンを押すと出る4つの選択肢(通知の受け方):
>   - **Participating and @mentions** = 自分が書き込んだ話題と、自分の名前が呼ばれた時だけ。
>   - **All Activity** = そのリポジトリの全部の動き。**これが「はい」の状態です。**
>   - **Ignore** = 何も受けない。
>   - **Custom** = 種類を選ぶ(Issues / Pull requests / Releases / Discussions / **Security alerts** …)。この中の「Security alerts」にチェックがあれば、非公開の脆弱性報告の知らせも来ます。
