## 追記(第127ラウンド): 「:自動更新」のカバレッジ

自動更新(v1.87.0)の設計条件はverify171が担当: A1=チェックの存在/初期値オフ/永続/ダイアログ反映・
A2=デバウンス(3変更→書き込み1回)・A3=内容の変更なし(指紋一致)は書かない・A4=**競合ガード**
(ドライブが先に進んでいたら書かずに👎)・A5=トークン切れ→🈚️・A6=visibilitychangeで即時1回・
A7=オフなら何も起きない。
