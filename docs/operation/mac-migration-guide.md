-------------------------------------------------------------------------------
## 0. この手順書の前提
-------------------------------------------------------------------------------

- 対象: たけちゃんさんのMac。Claudeのサブスクリプション(Pro/Max)アカウントを既にお持ちで、
  claude.ai/codeのweb版で開発してきた状態から、Macにも作業環境を増設する。
- システム要件: macOS 13.0以降・メモリ4GB以上。サブスクリプションはPro以上が必要
  (無料プランではClaude Codeは使えません。たけちゃんさんは条件を満たしています)。
- 「移行」と書いていますが実体は「**増設**」です。web版はそのまま残り、記憶の正はGitHubのままです。
- 途中でやめても・失敗しても、記憶(リポジトリ)には影響しません(手順9の安全網を参照)。
- 所要時間の目安: 手順1〜6で30〜45分ほど。
- 別の道: デスクトップアプリ(Claude Code内蔵)を入れる方法もあります。この手順書は
  ターミナル版(CLI)で書きますが、どちらでもCLAUDE.md・スキル・設定は同じに読まれます。
- ターミナルの画面には2種類あります。この区別だけ覚えておいてください:
  - **シェル**(`フォルダ名 %` のような表示) … Macへの命令を打つ画面。手順のコマンドはここへ。
  - **Claudeの対話画面** … `claude`と打つと始まる画面。日本語でお願いを書く。`/exit`で抜けてシェルに戻る。

## 2. インストール
-------------------------------------------------------------------------------

ターミナル(アプリケーション→ユーティリティ→ターミナル)を開いて、公式インストーラを実行します:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

- これはAnthropic公式のインストール方法です(Node.js等の事前準備は不要)。
- 本体は自動更新されるので、アップデート作業は不要です(起動コマンドは`~/.local/bin/claude`に入ります)。
- 終わったら、ターミナルをいったん閉じて開き直し、動作確認:

```bash
claude --version
claude doctor
```

バージョン番号が表示され、doctorが問題なしと言えばインストール完了です。

もし「command not found: claude」と出たら(静かな失敗の型):
1. まず `~/.local/bin/claude --version` を試す。
2. これで動くなら本体は無事で、PATH(コマンドの通り道)が未設定なだけ。次を実行:
   `echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc`
3. ターミナルを閉じて開き直し、もう一度 `claude --version`。

## 3. 作業フォルダの準備(iCloudの外)
-------------------------------------------------------------------------------

判断資料の通り、Claude Codeの作業場所は**iCloudの外**に作ります。

まずgitが使えるかを確認(VSCodeで使ってきたので、たいてい入っています):

```bash
git --version
```

インストールを促すダイアログや「invalid active developer path」が出たら、`xcode-select --install`を
実行して完了を待ち、もう一度`git --version`。バージョンが出たら次へ。

```bash
mkdir -p ~/ClaudeRoot
cd ~/ClaudeRoot
```

- `~`はホームフォルダ(/Users/あなたの名前)で、ホーム直下はiCloud同期の対象外です。
  ※`~/Documents`(書類)と`~/Desktop`は「デスクトップと書類」の同期がONだとiCloud圏内なので、
  そこには置かないでください(ホーム直下の`~/ClaudeRoot`が安全です)。
- 以前todo.mdに書かれていた「/ClaudeRootを作成し、それ以下に/soranotsuji-devなどを配置」の
  構想そのままです。
- 既存のiCloud上の`soranotsuji-dev-local`は**触りません**(そのまま書斎として使えます)。

## 5. pushできるようにする(GitHubの認証)
-------------------------------------------------------------------------------

**大事な前置き: ターミナルのgitは、VSCodeのGitHubログインを引き継ぎません。**
cloneは公開リポジトリなので無認証でできましたが、**push(アップロード)には認証の一手間が要ります**。
道は2つあり、どちらでも大丈夫です。

### 道A. pushはいつものVSCodeで行う(新しい道具ゼロ・おすすめ)

- VSCodeで「フォルダーを開く」→ `~/ClaudeRoot/soranotsuji-dev` を開く。
- コミットまではClaudeがローカルで行い、**プッシュだけVSCodeのいつもの同期ボタン**で行う。
  (新しいブランチの初回だけは「ブランチの発行(Publish Branch)」ボタンになります。同じことです)
- VSCodeのGitHubログインがそのまま使えるので、設定は何も増えません。

### 道B. ターミナルだけで完結させる(GitHub CLIを入れる)

1. GitHub CLI(gh)の公式macOSインストーラ(.pkg)を https://cli.github.com/ から入れる。
2. ターミナルで `gh auth login` → ブラウザが開くので、いつものGitHubアカウントでログイン。
3. `gh auth status` で確認。これでターミナルのgit pushも通るようになります
   (通らない場合だけ `gh auth setup-git` を一度実行)。

## 6. 初回起動・ログイン・記憶の接続確認
-------------------------------------------------------------------------------

**必ずリポジトリの中で**起動します(最初に信頼を聞かれる範囲がこのフォルダになります):

```bash
cd ~/ClaudeRoot/soranotsuji-dev
claude
```

1. 「このフォルダを信頼するか」と聞かれたら → はい(Yes)。
2. 初回はログイン方法を聞かれます → 「**Claudeアカウント(サブスクリプション)**」を選ぶと
   ブラウザが開くので、いつものアカウントでログインして許可。
   (API従量課金のConsoleアカウントと並びますが、いつものサブスクの方です)
3. CLAUDE.mdが自動で読み込まれます(web版と同じ規約)。`/usage`と打つとプランの使用状況が
   見られます(web版とMacの使用量は同じプールで合算)。
4. **ブランチのお願い(ローカルならではの1行)**: web版と違い、ローカルは`claude/…`ブランチを
   自動では作りません。作業を始める前にClaudeへこう頼みます:
   「作業用ブランチ(例: claude/local-2026-08-04)を作ってから作業してください。mainには直接コミットしないでください」
5. いつものセッション開始の会話文を打ちます:

```
/docs/order.md、/docs/todo.md、/docs/order-log/order-YYYY-MM-DD.md を読んで、前回の作業状態を把握してください。
未解決の質問や気になる点があれば、教えてください。
そして、今までのように、/docs/order.md にご回答をお願いいたします。
```

   ※YYYY-MM-DDは直近の作業日に置き換えてください(例: order-2026-07-26.md)。
   分からなければその部分は削って、order.mdとtodo.mdだけでも大丈夫です。

6. **合格判定**: Claudeが前回までの経緯(パール槍ヶ岳の旅・koushi.js・PAD書式の判断待ち…)を
   正しく語れたら、記憶の接続確認は完了です。
   **語れなかったら**: 最新ラウンドのブランチが未マージの可能性が高いです。手順1の4つ目に戻り、
   web版側(またはGitHub上)でマージしてから、Claudeに「git pullして最新にしてください」と頼んで
   もう一度どうぞ。
7. 終わる時は `/exit` と打つとClaudeの対話画面が閉じ、シェル(`フォルダ名 %`)に戻ります。
8. 回帰テストのハーネスはローカルにはまだ無いので、必要になった時にClaudeへ
   「kaikiスキルの手順でハーネスを作って」と頼めば、自分で構築します
   (Node.js等が足りなければClaudeがその場で案内します。ローカルは一度作れば消えません)。

## 7. 権限とネットの設定(必要なら)
-------------------------------------------------------------------------------

既定のままでも安全です(作業フォルダの外への書き込み・ネット検索や取得は許可を求めてきます)。
恒久ルールにしたい場合の書き場所は:

- **Macの個人的な禁止ルールは `~/.claude/settings.json`(Mac全体・自分専用)へ**。
  リポジトリ側の`.claude/settings.json`はGitHub経由でweb版とも共有されるため、
  個人のフォルダパスはそちらへ書かないでください。

例(`~/.claude/settings.json`):

```json
{
  "permissions": {
    "deny": [
      "Read(//Users/あなたの名前/Documents/**)",
      "WebSearch"
    ]
  }
}
```

- 「あなたの名前」はMacのアカウント名に置き換えます(シェルで`whoami`と打つと表示されます)。
- 設定したら効き目の確認を: Claudeに書類フォルダの中のファイルを読むよう頼んでみて、
  拒否されることを確かめる(無いことのテストの精神です)。
- ネットの例: `"WebSearch"`と`"WebFetch"`をdenyに入れると全面禁止。
  特定サイトだけ許すなら`"allow": ["WebFetch(domain:github.com)"]`のような中間もあります。

## 8. web版との併用ルール
-------------------------------------------------------------------------------

2つの環境は「同じリポジトリを触る2人の作業者」なので、ルールはgitの普通の作法だけです。

1. **作業を始める前に必ずpull**(今のweb版運用と同じ。CLAUDE.mdの規約もそのまま)。
2. **同じブランチを同時に2つの環境で書かない**(ラウンドの往復は、どちらか片方の環境で完結させる)。
3. **終わったら必ずpush**(プッシュしていない作業を溜めない — 唯一にして最大のルール)。
4. **ローカルの作業ブランチは`claude/local-…`を毎回作る**(手順6の4。mainへ直接コミットしない。
   マージはいつものたけちゃんさんの作業のまま)。
5. order.mdの往復・コミットハッシュの添付運用は、どちらの環境でも同じに使えます。

豆知識(使わなくても困りません):
- シェルで `claude --teleport` … web版のセッションを選んで、会話履歴の写しをMacへ持ち込めます
  (webのセッションは残ります。写しなので続きはwebへ反映されません)。
- Remote Control … Macで動かしているセッションをclaude.aiに繋いで、iPhoneから進捗確認・指示が
  できます(実行はMac側のまま)。

## 9. 困った時(ロールバックと安全網)
-------------------------------------------------------------------------------

- **やり直したい(クローンを消して作り直す)**: 削除の前に、必ず指差し確認を1つ:
  1. `~/ClaudeRoot/soranotsuji-dev`をVSCodeで開き、ソース管理に保留中の変更が無いこと・
     未プッシュのコミット(同期ボタンの上向き矢印の数字)が無いことを見る。
     またはClaudeに「コミットやプッシュがされていない作業が無いか確認して」と頼む。
  2. 未プッシュの作業があれば、先にプッシュする(または、消さずにフォルダ名を変えて脇に退避)。
  3. 確認できたら、Finderでフォルダをゴミ箱へ(取り消しが効くのでrm -rfより安全)。手順4からやり直し。
  プッシュ済みの記憶はGitHubに無傷です。
- **Claude Code自体をやめたい**: アンインストールしてもリポジトリ・記憶に影響はありません。
  シェルで `rm -rf ~/.local/bin/claude ~/.local/share/claude`(本体の削除)。
  Mac側の設定・会話履歴まで消したい場合のみ `rm -rf ~/.claude` も実行(リポジトリには影響なし)。
- **web版に戻りたい**: いつでもどうぞ。何も設定は要りません(元々消えていないので)。
