## 初期値と保存・URL再現の方針(第36ラウンドの整合性調査より)
-------------------------------------------------------------------------------
-------------------------------------------------------------------------------


### 目的:
- 設定値・状態の「初期値がどこから来るか」を1枚で見えるようにする。
- 3つの入口 — ①初回アクセス(履歴的に初回) ②再訪(ブラウザを閉じて再アクセス) ③URLパラメータ付き — での初期値の違いを明確にする。
- 「URLでプレビューを再現できる範囲」と「閲覧者の環境に依存する範囲」の境界を記録する。

### 概要(起動時の値の決まり方):
- 起動シーケンスは一本道:
  1. コード内の既定値(appState定義)
  2. localStorage復元(`soranotsuji_app` 1キーへ全設定を保存。キー毎の個別マージ+正規化)
  3. URLパラメータ適用(**modeキー必須**。無いURLは全パラメータ無視)
  4. UIへ反映(setupUI→各入力欄へappState値を書き込み)
- Googleドライブ(soranotsuji-app.json)は**手動同期のみ**(読み込むとページ再読込→次回起動が②として読む)。起動時に自動では読まない。
- 用語: ①=S1(既定値のみ) / ②=S2(既定値+localStorage) / ③=S3(S2の上へURL項目だけ上書き)。

### 「①と②が異なる」= 保存されて持ち越されるもの(まとめ):
- 位置(観測点/目的点/登録場所)・組込天体の表示/色/線種・My系リスト全部・大気差/気象・
  辻ラインON/OFF・辻検索/辻メッシュの検索条件・基本オプション・宙の窓の大半・花火モード(1.38.0〜)・
  Google連携の簿記(フォルダ名/同期時刻)。
- 逆に「毎回リセット」は意図的なもの: 日時(常に今)・パネル開閉・辻ライン365・地図ズーム/ベース地図・
  宙の窓の焦点距離系(DEMタイル過剰取得防止)・ログイン状態。

### URLキーが無い入力フォーム(=プレビュー再現の限界。閲覧者の環境の値になる):
- **大気差補正ON/OFF・気象3欄**(計算結果に影響) / **組込天体の色・実線/破線**(見た目に影響)
- **基本オプション全部**(天の川基準点・オフセット中心角・天体儀の表示天体名/星座線/星座領域/星座名称/並び順・標高グラフ除外範囲)
- 宙の窓の文字サイズ(soraLabelScale) / 観測点/目的点ラジオ / My系リスト(専用URL機能で1行single共有は可能)
- セッション専用(そもそも保存対象外): ベース地図種別・地図ズーム・天体儀の前景/後景/回転・
  辻メッシュパネル内のコントロール(時刻スライダー/時間幅/ε/グレー/エリア/レイヤチェック)・各メニュー開閉
- ※これらをURLに含めるかは今後の判断(含めるほどURLは長くなる。短縮URL辞書の版上げが必要)。

### 第36ラウンドで直した整合性の問題:
1. **花火モード設定が保存されるのに復元されない**(実装漏れ) → 復元を追加。
2. **Myセット: 同期済み・非オフラインの非表示セットを「保存」するとシートを空で上書き**(データ消失経路) → 書込前にガードし「読み込み」を案内。
3. **Drive同期の[New]が常にローカル優位**(内容が変わらない簿記保存でもsavedAtが進むため) → 「前回同期からの変更の有無」(指紋/DriveのmodifiedTime差)で判定。
4. **シート同期のたびにapp.jsonが「差あり👎」になる**(シート簿記が指紋に混入) → 簿記を指紋から除外。
5. **機能封鎖中にシートを読み込むと端末のMy宙検索が消える**(封鎖中はタブを読まないため空で置換) → 端末の現値を温存。
6. **辻検索URLの基準方位角/視高度が自動再計算で上書きされ再現されない**(辻メッシュ/宙の窓には保護があった) → 同じ保護を追加。
7. 保存の容量超過(QuotaExceeded)が無音で失敗 → 一度だけ警告表示。辻検索期間の正規化(1..36500)も追加。

### 記録済みの残課題(今回は修正せず・要判断):
- **URLで開くと、その内容が以後の操作でlocalStorageへ永続化される**(共有URLを開いただけで自分の保存済み検索条件が置き換わり得る)。
  「URL由来の値はセッション限定にする」等の対策は挙動変更が大きいため、方針を決めてから(order.md その32で提案)。
- Drive保存がlocalStorageの**全キー**を含む(同一オリジンの他アプリのキーが混入し得る)・
  2種類のバックアップ(メニュー/reset.html)が同名パターンで非互換・
  Driveアップロード中の編集が「同期済み👍」を偽装し得る競合・
