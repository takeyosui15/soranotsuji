# デッサン（dessin）

## Myセットメニュー
-------------------------------------------------------------------------------
-------------------------------------------------------------------------------


### 目的:
- My辻検索メニュー、My観測点メニュー、My目的点メニュー、My天体メニューの内容を一つの組みとするMyセットを1つのリスト項目として、他のリスト項目と丸ごと差し替え、複製、削除できて管理でき、GoogleドライブのスプレッドシートのMyセットと同期管理もできるものを提供する。
### 概要:
- 機能概要
  - 現在表示されているMy辻検索メニュー、My観測点メニュー、My目的点メニュー、My天体メニューの内容の組みを1件のMyセットとして、他の組みのMyセットと丸ごと差し替える「切り替え表示」機能がある。
  - ローカルストレージの内容が反映された「既定のセット」(名称固定)がある。
  - Myセットの追加・削除ができる。
  - Myセットの複製がある。
  - Myセットの名前変更ができる。
  - MyセットをログインしているGoogleドライブのスプレッドシートに書き出す「保存」機能と、スプレッドシートから内容を読み込む「読込」機能がある。
  - Myセットをオフラインで使用できる「オフライン」選択肢がある。
  - ローカルストレージのMyセットとGoogleドライブのスプレッドシートのMyセットの更新状態がわかる機能がある。
  - ボタンを押すとGoogleドライブの該当のスプレッドシートを開く機能がある。
  - 「ファイル選択ダイアログ(Google Picker)」でGoogleスプレッドシートのMyセットを追加できる。
  - 既定のセットと切り替え表示中のMyセットは、ローカルストレージに必ず保持している。その他のMyセットは、オフライン指定されたMyセットのみ。
    - 基本的にMyセットは、ローカルストレージの容量が数MB程度なので、Googleドライブにログインして使用する機能である。できるだけ、GoogleスプレッドシートのMyセットを作成して、使用する機能である。

### 仕様詳細:
- GoogleスプレッドシートのMyセット
  - GoogleスプレッドシートのMyセットは、以下のシート名のシートを持ち、その内容を保持する。
    - My辻検索、My観測点、My目的点、My天体
    - 各シートは、 各メニュー(My辻検索、My観測点、My目的点、My天体)のCSV出力したものをそのまま貼り付けて保存した内容と同じ内容を保持できる。
    - 各シートは、以下の初期状態を持つ
      - 1行目:1列目:#このようにコメントを記載できます。
      - 2行目:1列目:#
      - 2行目:2列目:これもコメント行です。複数行、記述できます。
      - 3行目:1列目:#
      - 3行目:2列目:先頭から連続する#行がコメント行になります。
      - 4行目:1列目以降:各シートの見出し行
- 共通機能/デザイン
  - テキストボックス:
    - 未入力でフォーカスが外れた場合、元の値を復元する。
    - title属性でテキストボックスの内容をツールチップで表示する。
    - input:type=textは、最大文字数150文字とする。
    - XXS対策で、入力内容をタグエスケープする。
    - フォーム、appState、ローカルストレージで、整合性が取れるようにする。
  - 背景色:
    - 1〜N+3段目は、背景赤で、少し透明で、背景の地図が見える。
- コントロールの初期状態
  - ローカルストレージのMyセットリストの登録内容によって、登録されている内容を各Myセットごとに、4段目以降に行を追加して、コントロールに読み込んで表示する。
    - 読み込みに時間がかかる場合もあるので、非同期処理として実装する。
      - 読み込み中は、進行中のクルクルを表示する。絵文字の時計のアイコンの針がくるくる回転する。
  - ローカルストレージのMyセットリストがない場合は、0件（4〜N段目がない状態）になる
