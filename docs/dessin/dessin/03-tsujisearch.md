# デッサン（dessin）
-------------------------------------------------------------------------------
-------------------------------------------------------------------------------
## 辻検索メニュー
-------------------------------------------------------------------------------
-------------------------------------------------------------------------------


### 目的:
- 例えば、富士山の右斜め上に月がある日付と時間を求められるようにするため。
- 辻ラインは、目的点緯度経度、観測点標高、目的点標高、観測点視高度から位置を逆算するため、精度が出ないので、高い精度のものが必要なため。
### 連動(第81ラウンド・方針転換):
- 辻メッシュ検索メニューと同じ名前の項目(検索期間・基準方位角/視高度・辻オフセット方位角/視高度・許容範囲方位角/視高度・検索中心・オフセット中心角・月齢/時間/曜日/月間/標高フィルタ)は**連動する**(どちらのメニューで変えても、もう一方に映る)。
- 連動しない項目: 精度フィルタ(辻検索=選択式・辻メッシュ=読み取り専用固定で意味が違うため)。
### 概要:
- 機能概要
  - 辻検索
    - 位置情報から、オフセットありで、リストアップ対象の許容範囲ありで、検索中心からどれくらい離れているかを、検索期間内で日付と時刻のリストアップをする。
    - 算出対象の天体は、天体リストで表示がオンになっているものを対象とする。
- デザイン概要
  - 0段目:
    - 1. 「辻検索」ラベル:
      - 太字、左寄せ
    - 2. 「辻検索」トグルボタン:
      - 中央寄せ
      - 押されている状態の時は、ラベル名を太字で、ボタン色を黄色にする。
    - 3. 「▼」ラベル:

    - 共通事項:
      - タップすると、辻検索メニューが開閉する。
      - 背景グレー、不透明
      - 初期状態:閉じている。
  - 1段目:
    - 4. 「File取得」ボタン:
      - このボタンを押下すると、辻検索を実行し、結果をCSVでFile取得する。
      - このボタンを押下すると、実行する前に、確認メッセージ「辻検索を実行し、結果をCSVでFile取得しますか？」（window.confirmで、OK、キャンセル）が表示される。
        - File出力する項目などの詳細は、仕様詳細を参照のこと。
  - 2段目:

      - 検索期間を日で指定する。
      - 初期値:365

      - プレースホルダー:「最大36500日(100年間)」
  - 3段目:

      - 基準方位角を観測点緯度経度と目的点緯度経度から算出
      - 初期値:算出値
      - 制約:0〜360、ステップ0.01
      - プレースホルダー:「北から時計回り(°)」
  - 4段目:
    - 7. 「基準視高度:」テキストボックス:

      - 初期値:算出値
      - 制約:−360〜360、ステップ0.01
      - プレースホルダー:「水平から上向き(°)」
  - 5段目:
    - 8. 「辻オフセット方位角:」テキストボックス:
      - 基準方位角からの検索中心のズレ量のオフセット方位角で入力する。
      - 初期値:0
      - 制約:-360〜360、ステップ0.01
      - プレースホルダー:「基準から時計回り(°)」
  - 6段目:
    - 9. 「辻オフセット視高度:」テキストボックス:

      - 初期値:0
      - 制約:−360〜360、ステップ0.01
      - プレースホルダー:「基準から上向き(°)」
  - 7段目:
    - 10. 「辻オフセット方位距離:」テキストボックス:
      - 観測点での辻オフセット方位角を目的点での距離に直したMath.tan()で表示する。
      - 制約:読み取り専用
  - 8段目:
    - 11. 「辻オフセット視高距離:」テキストボックス:

      - 制約:読み取り専用
