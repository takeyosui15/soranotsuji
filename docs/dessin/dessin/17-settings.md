# デッサン（dessin）

## 設定メニュー
-------------------------------------------------------------------------------
-------------------------------------------------------------------------------


### 目的:
- 気差係数を設定し、気差係数の有効/無効を設定できるものとする。
### 概要:
- 機能概要
  - 気差係数の有効/無効の変更
  - 気差係数を気圧/気温/気温減率から算出できる。
  - リセットボタンと登録ボタンがある。
  - 気差係数が無効の時は、読み取り専用になる。
- デザイン概要
  - My天体メニューの下に配置する。
  - 0段目:
    - 1. 「設定」ラベル:
      - 太字、左寄せ
    - 2. 「▼」ラベル:
      - 右寄せ
    - 共通事項:
      - タップすると、設定メニューが開閉する。
      - 背景グレー、不透明
      - 初期状態:閉じている。
  - 1段目:
    - 3. チェックボックス:
      - 「気圧」「気温」「気温減率」のテキストボックスの読み取り専用にする/しないを切り替えて、気差係数を全ての処理で有効/無効を切り替える。
      - **第158(v1.97.0)・依頼者の方針変更**: チェック**オン=気象条件から算出したK(既定)・オフ=K=0(気差なし)**。「オフでも0.132」(第157)は取り下げ(K=0の見え方の検証ができなくなるため)。天体の大気差は下の10.「気差オプション」に分けた。旧い保存データは一度だけ両方オンの新既定へ(印 refractionV3)。
      - (第157(v1.96.0)の記録) 「無効」=気差なし(k=0)ではなく、**係数欄に表示されている値で全ての処理が計算する**: チェックオフ=測量標準の0.132・オン=気象条件から算出した値(本体の `refractionKInUse()` 1本。標高グラフ・辻検索/My辻・辻メッシュ・可視マップ・辻ライン・宙の窓の地形/建物/花火)。
        天体の見かけ高度の大気差(Astronomy.Horizonの'normal')はこれまでどおりチェックのオン/オフに従う(別の量。設定の気圧・気温は反映されない)。値の置き場は `sora-constants.js`(デッサン33)。
    - 4. 「気差係数」テキストボックス:
      - 常に読み取り専用。
  - 2段目:
    - 5. 「気象条件からKを算出」ラベル:
  - 3段目:
    - 6. 「気圧」テキストボックス:
  - 4段目:
    - 7. 「気温」テキストボックス:
  - 5段目:
    - 8. 「気温減率」テキストボックス:
  - 6段目:
    - 9. リセットボタン:
  - 7段目:
    - 10. 「:気差オプション(Astronomy Engine気差補正)」チェックボックス
      - Astronomy Engineの気差補正をかける(オン)か、かけないか(オフ)
      - 既定値:オフ
      - **第158(v1.97.0)の判断: 既定値はオン**。依頼者「二重に気差補正がかからないのであれば、既定値はオンで良い」→二重にはかからない(地上のKは目的点→目の光の曲がり・こちらは天体→目の光の曲がりで、別の光線)。
        appState.astroRefraction(保存・共有URL v22・ワーカーへは astroRefraction)。辻検索・辻メッシュ・My辻・辻ライン・宙の窓の天体の見かけ高度と、天体リストの高度・恒星(My天体)の出没時刻・日月の出没の高度に効く。太陽・月・惑星の出没時刻(Astronomy Engine の SearchRiseSet=常に標準の大気差つき)と天体儀の向きは変わらない(第158のレビューで文言を正した)。設定の気圧・気温は反映されない(Astronomy Engineの標準大気)。
  - 8段目:
    - 11. 登録ボタン:
- 共通機能/デザイン
  - 背景色:
    - 1段目は、背景白で、少し透明で、背景の地図が見える。
    - 2〜6段目は、グループにして、薄い青色の背景色にする。
