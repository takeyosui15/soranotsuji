# デッサン（dessin）
-------------------------------------------------------------------------------
-------------------------------------------------------------------------------
## バックアップメニュー
-------------------------------------------------------------------------------
-------------------------------------------------------------------------------


### 目的:
- Homeボタン、推し山ボタン、表示天体、My天体、My観測点、My目的点、My辻検索、設定のリストの一括バックアップをすることで、データの保護と、デバイス間のデータの同期を可能とするものとする。
### 概要:
- 機能概要
  - JSON形式のファイルで、一括バップアップとインポートができる。
  - appState、ローカルストレージとの整合性が保てる。
- デザイン概要
  - 設定メニューの下に配置する。
  - 0段目:
    - 1. 「バックアップ/インポート」ラベル:
      - 太字、左寄せ
    - 2. 「▼」ラベル:
      - 右寄せ
    - 共通事項:
      - タップすると、バックアップメニューが開閉する。
      - 背景グレー、不透明
      - 初期状態:閉じている。
  - 1段目:
    - 3. 「バックアップ」ボタン:
      - このボタンを押下すると、実行する前に、確認メッセージ「ローカルストレージの内容をバックアップファイルに全て出力しますか？」（window.confirmで、OK、キャンセル）が表示される。
        - 確認メッセージの後にブラウザからJSONファイルをダウンロードできる。
      - ファイル名にバックアップ実施日時を含める。
        - soranotsuji-app-バックアップ-YYYYMMDD-hhmmss.json
      - ローカルストレージの中にローカルストレージの最終更新日時を含める。
      - ローカルストレージの情報をJSON形式でバックアップする。
    - 4. 「インポート」ボタン:
      - JSONファイルから一括インポートできる。
      - このボタンを押下すると、実行する前に、確認メッセージ「ローカルストレージの内容をバックアップファイルから全て上書き入力・登録しますか？」（window.confirmで、OK、キャンセル）が表示される。
        - 確認メッセージの後にファイル選択ダイアログが開いて、デバイス内のファイルを選択できる。
      - appState、ローカルストレージと整合性が取れる。
      - My観測点、My目的点の地図上のマーカーも更新される。
  - 2段目:
    - 5. 「Googleドライブ」ラベル：
      - ローカルストレージの内容を保存しているユーザのGoogleドライブの保存先を示す。
  - 3段目:
    - 6. 「ログイン」ボタン:
      - Googleアカウントにログインするボタン。
      - 制約:ログイン中は非活性。
    - 7. 「ログアウト」ボタン:
      - Googleアカウントからログアウトするボタン。
      - 制約:ログインしていない場合は非活性。
  - 4段目:
    - 8. 「宙の辻フォルダ名:」ラベル:
  - 5段目:
    - 9. 宙の辻フォルダ名テキストボックス:
      - テキストボックス
      - 初期値:/soranotsuji-宙の辻
      - 制約:/で始まること
  - 10段目:
    - 10. 「登録」ボタン:
    - 宙の辻フォルダ名を変更した時に、反映させるためのもの。
  - 6段目:
    - 11. 「設定フォルダ名:」ラベル:
  - 7段目:
    - 12. 設定フォルダ名テキストボックス:
      - 読み取り専用テキストボックス
      - 初期値:/(宙の辻フォルダ名)/設定
  - 8段目:
    - 13. 「Myセットフォルダ名:」ラベル:
  - 9段目:
    - 14. Myセットフォルダ名テキストボックス:
      - 読み取り専用テキストボックス
      - 初期値:/(宙の辻フォルダ名)/Myセット
  - 10段目:
    - 15. 「Googleドライブ最終更新日時:」ラベル
  - 11段目:
    - 16. Googleドライブにsoranotsuji-app.jsonを保存した最終更新日時を表示
      - 例:2026年02月09日(木) 19:32:16
  - 12段目:
    - 17. Googleドライブにローカルストレージを保存した容量を表示
      - 例:ローカルストレージ: 1,024KB
- 共通機能/デザイン
  - 背景色:
    - 1段目は、背景白で、少し透明で、背景の地図が見える。
### 仕様詳細：
- JSON形式
  - ファイルの文字コードと改行コードは、MS Excel,Google SpredSheet,Windows,Mac,Android,iPhoneで互換性のあるものとする。
