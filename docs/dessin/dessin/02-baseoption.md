# デッサン（dessin）
-------------------------------------------------------------------------------
-------------------------------------------------------------------------------
## 基本オプションメニュー
-------------------------------------------------------------------------------
-------------------------------------------------------------------------------


### 目的:
- 辻ラインボタン、天体儀ボタン、標高グラフボタン、辻検索ボタン、宙の窓ボタンの個々のボタンのオプションや、共通する基本オプションなどを提供する。
### 概要:
- 機能概要
  - 基本オプション
    - 天の川の検索中心に使用される中心のオフセット点や、天体儀のオプションなどを指定する。
- デザイン概要
  - 凡例:0️⃣:段抜き、1️⃣:1行目、2️⃣:2行目、1️⃣:2️⃣:1行目の中の2行目、以下同様
  - 0段目:
    - 1. 「基本オプション」ラベル:
      - 太字、左寄せ
    - 2. 「▼」ラベル:
      - 右寄せ
    - 共通事項:
      - タップすると、基本オプションメニューが開閉する。
      - 背景グレー、不透明
      - 初期状態:閉じている。
  - 1段目:
    - 3. 「辻ライン」ラベル:
      - 辻ラインにまつわるオプションを指定する。
  - 2段目(第85ラウンド・怒号の項目12で刷新。旧「天の川の基準点」ラジオ2個は撤去=
    第82ラウンドの「:天の川オプション」チェックボックスが同じ状態(オン=オフセット点/オフ=中心座標)を担うため):
    - 4. 「:辻オフセット方位角/視高度」チェックボックス:
      - 辻ラインに、辻オフセット方位角/視高度の検索中心のズレを含めるか(オン=検索中心の辻ライン・オフ=基準点の辻ライン)。
      - 方位角のズレは線の回転、視高度のズレは「天体が目的点の見かけ高度+ズレ角に来る位置」として効く。
      - オンの間は辻オフセットの入力変更でも辻ラインが引き直される。
      - **辻ライン365にも効く**(第96ラウンド・依頼者指示): 365日の線も同じズレ込みで描き、
        チェックやオフセットの変更で計算済みの線を捨てて引き直す。
        検索中心オプションが「線」の時の仰角1°置きの刻み(複数線)は365には適用しない
        (365日×天体×刻みで50万点規模が数十倍に爆発するため。オフセット点の1本で代表する)。
      - 初期値:オン
      - 制約:ローカルストレージに保存する(URLキーはv16で追加済み=tsujiLineIncludeOffset)。
  - 3段目:
    - 5. 「検索中心オプション」ラベル:
      - 検索中心を「点」か「線」の範囲かで選択する(辻検索・辻メッシュ検索と3面連動)。
  - 4段目:
    - 6. 「:辻オフセット点」ラジオボタン:
      - 検索中心を辻オフセット点の「点」にする。辻検索・辻メッシュ検索の検索中心オプションと連動する。
      - 初期値:オン
  - 4.5段目:
    - 6.5 「:基準点から辻オフセット点までの線」ラジオボタン:
      - 検索中心を基準点から辻オフセット点までの「線」の範囲にする。辻検索・辻メッシュ検索の検索中心オプションと連動する。
      - この場合の辻ラインは、厳密には面になるため、辻オフセット仰角を1°置き(仰角のズレが0のときは方位角を1°置き)に
        ずらした複数の実線を描く(刻みは上限37本=超える場合は等間隔に広げる。前日/翌日線・精度境界の装飾は両端の線だけ)。
      - 初期値:オフ
  - 5段目:
    - 水平線
  - 6段目:
    - 7. 「天体儀」ラベル:
      - 天体儀にまつわるオプションを指定する。
  - 7段目:
    - 8. 「:表示天体」チェックボックス:
      - 表示天体メニューで指定された天体の情報を表示/非表示にするチェックボックス。
        - 天の川の場合
          - 以下の情報を表示/非表示にする。
            - NASA(https://svs.gsfc.nasa.gov/4851/)からダウンロードした天の川の写真(milkyway-skymap.webp)。
            - 「天の川の環」を示す白い線。
            - 天の川の中心座標を示す赤いマーカーとその方向を示す中心からの白い方位線。
            - 天の川の中心座標からのオフセット点を示す天体色のマーカーと、その方向を示す中心からの天体色の方位線。
              (位置は正典のgetMilkyWayBaseRaDec=検索・軌跡と同一点。第122ラウンドで反転漏れ
              [第93の符号統一の取り残しで逆回りだった]を一本化により修正)
            - 天体儀の右側か左側にある表示天体名の名称と、その名称からの引き出し線が、オフセット点を指し示す線。
        - 惑星の場合
          - 以下の情報を表示/非表示にする。
            - 惑星の軌跡(前面=チューブ実線・背面=破線3本重ね。太さは中心からの方位線の2倍。
              第117ラウンドで細線→方位線と同じ太さへ、第118ラウンドでさらに2倍=スマホでの
              見やすさの依頼者指定。等赤緯円のためトーラスで厳密描画)
            - 惑星の視半径を反映した天体色のマーカーと、その方向を示す中心からの天体色の方位線。
            - 天体儀の右側か左側にある表示天体名の名称と、その名称からの引き出し線が、表示天体を指し示す線。
        - 恒星の場合
          - 以下の情報を表示/非表示にする。
            - 恒星の軌跡(線の形は惑星の軌跡と同じ)
            - 恒星の位置を反映した天体色のマーカー(+)と、その方向を示す中心からの天体色の方位線。
            - 天体儀の右側か左側にある表示天体名の名称と、その名称からの引き出し線が、表示天体を指し示す線。
      - 初期値:オン
    - 9. 「:表示天体名」チェックボックス:
      - 天体儀の両側にある各表示天体名と、その表示天体名からの引き出し線が、各表示天体を指し示す線を表示/非表示にするチェックボックス。
      - チェックがオンの場合は、宙の窓のプレビュー画面にも表示天体名を表示する。
      - 初期値:オン
    - 10. 「:星座線」チェックボックス:
      - NASA(https://svs.gsfc.nasa.gov/4851/)からダウンロードした各星座の星座線(constellation-figures-skymap.webp)の写真を表示/非表示するチェックボックス。
      - チェックがオンの場合は、宙の窓のプレビュー画面にも星座線を表示する。
      - 初期値:オフ
  - 8段目:
    - 11. 「:星座領域」チェックボックス:
      - NASA(https://svs.gsfc.nasa.gov/4851/)からダウンロードした各星座の星座線(constellation-figures-skymap.webp)の写真を表示/非表示するチェックボックス。
      - チェックがオンの場合は、宙の窓のプレビュー画面にも星座領域を表示する。
      - 初期値:オフ
    - 12. 「:星座名称」チェックボックス:
      - 天体儀の両側にある各星座名称と、その星座名称からの引き出し線が、各星座線と各星座領域を指し示す線を表示/非表示にするチェックボックス。
      - チェックがオンの場合は、宙の窓のプレビュー画面にも星座名称を表示する。
      - 初期値:オフ
    - 13. 星座名称ソート順序リストボックス:
      - 星座名称のソート順序を指定するリストボックス。
      - 初期値:50音順
      - 制約:50音順、座標順のみ
  - 9段目:
    - 14. 「天の川オプション」ラベル:
  - (第82ラウンド・項目6の変更) グループラベルは「:天の川オプション」チェックボックスになった。
    オン=基準点がオフセット点・オフ=中心座標(基準点ラジオと同じ1つの状態の別の見た目。オフの間は角度入力を無効化し、値は保持)。
    オフセット中心角の±は「夏の天の川を上から見て時計回りが正」(第93ラウンドで内部値・保存・URL・CSV・Fileごと新しい符号に統一。第82の「画面だけ反転」は廃止)。
      - 天の川の計算に用いる基準点を天の川の中心座標(いて座付近)から、天の川の環の方向に、基準点をズラすことが出来るオフセット点のオフセット中心角(0°〜±360°、ステップ15°)を設定できる。
      - 基準点のオフセット点は、表示天体メニューの天体詳細(方位角、視高度、出入時刻など)や、辻ラインの計算基準、辻検索とMy辻検索のオプションで指定される点に反映される。
  - 10段目:
    - 15. 「オフセット中心角(°):」テキストボックス:
      - 天の川の計算に用いる基準点を天の川の中心座標(いて座付近)から、天の川の環の方向に、基準点をズラすことが出来るオフセット点のオフセット中心角を設定できる。
      - 天体儀のオフセット中心角と辻検索(My辻検索を除く)のオフセット中心角は、連動する。
      - 初期値:0
      - 制約:-360°〜+360°、ステップ1
  - 11段目:
    - 水平線
  - 12段目:
    - 16. 「標高グラフ」ラベル:
      - 目的点の半径〇〇m以内は、可視判定のNGを無視できるオプション。
  - 13段目:
    - 17. 「:除外範囲」チェックボックス:
      - 目的点/観測点の半径〇〇m以内は、可視判定のNGを無視できるオプション。
      - 初期値:オン
  - 14段目:
    - 18. 「目的点側(半径,m):」テキストボックス:
      - 初期値:15
        - 初期値の理由
          - 目的点自身のDEM画素による自己遮蔽(目的点が画素の隅にある最悪ケースで、
            z15画素の対角≒5.5m、DEM5系が無くz14フォールバックとなる地域で対角≒11m)と、
            鋭峰の平滑化写り込み(隣接1画素)を吸収する値。
          - 0にすると一切無視しない(上り視線では目的点直近の画素で構造的にNGになる)。
      - 制約:0〜10000、ステップ1
      - プレースホルダー:0〜10000m
    - 19. 「観測点側(半径,m):」テキストボックス:
      - 初期値:10
        - 初期値の理由
          - 観測点自身のDEM画素による自己遮蔽(観測点が画素の隅にある最悪ケースで、
            z15画素の対角≒5.5m、DEM5系が無くz14フォールバックとなる地域で対角≒11m)を
            吸収する値。5mだとz15整備地域でも最悪ケース(画素の隅)をわずかに覆えない。
          - 目的点側と違い鋭峰の平滑化写り込みの余裕は不要なため目的点側(15m)より小さくし、
            足元の実在の遮蔽(すぐ手前の岩や縁)を無視しすぎない範囲にする。
          - 0にすると一切無視しない(下り視線では観測点直近の画素で構造的にNGになり得る)。
      - 制約:0〜10000、ステップ1
      - プレースホルダー:0〜10000m
### 仕様詳細:
- 共通機能/デザイン
  - テキストボックス:
    - 未入力でフォーカスが外れた場合、元の値を復元する。
    - title属性でテキストボックスの内容をツールチップで表示する。
    - input:type=textは、最大文字数150文字とする。
    - XXS対策で、入力内容をタグエスケープする。
    - フォーム、appState、ローカルストレージで、整合性が取れるようにする。
  - 背景色:
    - 1〜9段目は、背景白で、少し透明で、背景の地図が見える。

- (第93ラウンドの変更) オフセット中心角の±は**内部値ごと**「夏の天の川を上から見て時計回りが正」へ統一した(第82の「画面だけの表示反転」を廃止。保存・URL・CSV・Fileも全て新しい符号。旧保存データはスキーマ2→3で自動読み替え)。
