# デッサン（dessin）
-------------------------------------------------------------------------------
-------------------------------------------------------------------------------
## 辻検索メニュー
-------------------------------------------------------------------------------
-------------------------------------------------------------------------------


### 目的:
- 例えば、富士山の右斜め上に月がある日付と時間を求められるようにするため。
- 辻ラインは、目的点緯度経度、観測点標高、目的点標高、観測点視高度から位置を逆算するため、精度が出ないので、高い精度のものが必要なため。
### 概要:
- 機能概要
  - 辻検索
    - 位置情報から、オフセットありで、リストアップ対象の許容範囲ありで、検索中心からどれくらい離れているかを、検索期間内で日付と時刻のリストアップをする。
    - 算出対象の天体は、天体リストで表示がオンになっているものを対象とする。
- デザイン概要
  - 0段目:
    - 1. 「辻検索」ラベル:
      - 太字、左寄せ
    - 2. 「辻検索」トグルボタン:
      - 中央寄せ
      - 押されている状態の時は、ラベル名を太字で、ボタン色を黄色にする。
    - 3. 「▼」ラベル:
      - 右寄せ
    - 共通事項:
      - タップすると、辻検索メニューが開閉する。
      - 背景グレー、不透明
      - 初期状態:閉じている。
  - 1段目:
    - 4. 「検索期間:」テキストボックス:
      - 検索期間を日で指定する。
      - 初期値:365
      - 制約:1〜36500(100年間)、ステップ1
      - プレースホルダー:「最大36500日(100年間)」
  - 2段目:
    - 5. 「基準方位角:」テキストボックス:
      - 基準方位角を観測点緯度経度と目的点緯度経度から算出
      - 初期値:算出値
      - 制約:0〜360、ステップ0.01
      - プレースホルダー:「北から時計回り(°)」
  - 3段目:
    - 6. 「基準視高度:」テキストボックス:
      - 基準視高度を観測点標高と目的点標高から算出
      - 初期値:算出値
      - 制約:−360〜360、ステップ0.01
      - プレースホルダー:「水平から上向き(°)」
  - 4段目:
    - 7. 「オフセット方位角:」テキストボックス:
      - 基準方位角からのズレ量のオフセット方位角で入力する。
      - 初期値:0
      - 制約:-360〜360、ステップ0.01
      - プレースホルダー:「基準から時計回り(°)」
  - 5段目:
    - 8. 「オフセット視高度:」テキストボックス:
      - 基準視高度からのズレ量のオフセット視高度で入力する。
      - 初期値:0
      - 制約:−360〜360、ステップ0.01
      - プレースホルダー:「基準から上向き(°)」
  - 6段目:
    - 9. 「オフセット方位距離:」テキストボックス:
      - 観測点でのオフセット方位角を目的点での距離に直したMath.tan()で表示する。
      - 制約:読み取り専用
  - 7段目:
    - 10. 「オフセット視高距離:」テキストボックス:
      - 観測点でのオフセット視高度を目的点での距離に直したMath.tan()で表示する。
      - 制約:読み取り専用
  - 8段目:
    - 11. 「オフセット回転角:」テキストボックス:
      - 観測点でのオフセット方位角とオフセット視高度から目的点方向を向いて、0時から時計回りに回転した角度を度(°)で表示する。
      - 制約:読み取り専用
  - 9段目:
    - 12. 「オフセット回転仰角:」テキストボックス:
      - 観測点でのオフセット方位角とオフセット視高度から目的点方向を向いて、回転角面を基準に上向きの仰角を度(°)で表示する。
      - 制約:読み取り専用
  - 10段目:
    - 13. 「許容範囲方位角:±」テキストボックス:
      - 検索中心から検索結果を表示する方位角の範囲
      - 初期値:15
      - 制約:0〜360、ステップ0.01
      - プレースホルダー:「検索中心から時計回り(°)」
  - 11段目:

      - プレースホルダー:「検索中心から上向き(°)」

      - 15.月齢フィルタのチェックボックスがオフの場合は、16.基準月齢と17.許容範囲月齢のテキストボックスが入力不可になる。
      - 初期値:オフ

      - 16.基準月齢から±の範囲で17.許容範囲月齢の数値の範囲の幅で、辻検索結果がさらにフィルタできる。
      - 初期値:15
      - 制約:0〜30、ステップ0.1
      - プレースホルダー:「0〜30」
      - 15.月齢フィルタがオフの時は、入力不可で、背景が灰色。

      - 16.基準月齢から±の範囲で17.許容範囲月齢の数値の範囲の幅で、辻検索結果がさらにフィルタできる。
        - 16.基準月齢が「0」で、17.許容範囲月齢が「2」の場合は、`SYNODIC_MONTH = 29.53058886`であるので、`27.53058886〜29.53058886`と`0〜2`の範囲でフィルタがされる。
      - 初期値:2
      - 制約:0〜15、ステップ0.1
      - プレースホルダー:「0〜15」
      - 15.月齢フィルタがオフの時は、入力不可で、背景が灰色。

### 仕様詳細:
- 2. 「辻検索」トグルボタン:
  - 機能概要
    - 位置情報から、オフセットありで、リストアップ対象の許容範囲ありで、検索中心からどれくらい離れているかの精度を表示して、検索期間内で日付と時刻のリストアップをする。
    - 算出対象の天体は、天体リストで表示がオンになっているものを対象とする。
    - リストは項目別にソート可能。
    - リストの表示項目:
      - 天体ID:アルファベット、数字
      - 天体名:テキスト
      - 精度記号:◎○△-
      - 精度角距離:「0.00000°」
      - 日付:「YYYY年MM月DD日」
      - 曜日:「(和暦)」:月火水木金土日
      - 辻時刻:「hh:mm:ss」
      - 時間帯:「`0時<=x<天文薄明[始]`」等
      - 日の出時刻:「hh:mm:ss」
      - 日の入時刻:「hh:mm:ss」
      - 月の出時刻:「hh:mm:ss」
      - 月の入時刻:「hh:mm:ss」
      - 月齢:「0.0」
      - 月齢アイコン:「🌕」
      - 方位角:「0.0000°」
      - 視高度:「0.0000°」
      - 視半径:「0.000°」
      - 標高グラフ: 「OK」/「NG」/「-」
    - 月齢、月齢アイコンは、月以外のどの天体の時も、その日付で、その辻時刻の時の月齢と月齢アイコンを表示する。
  - 精度記号
    - ◎: 天体の中心がほぼ目的点に重なる日（誤差±0.125°\[誤差範囲0.25°、およそ視半径以内\]）
    - ○: 天体の縁が目的点に接する範囲の日（誤差±0.25°\[誤差範囲0.5°、およそ視直径以内\]）
    - △: 目的点との誤差が天体の直径4倍以内の日（誤差±1°\[誤差範囲2°、およそ視直径×4以内\]）
    - -: 目的点との誤差が上記以上で、指定した許容範囲以内に収まる日
  - アルゴリズム概要:
    - 1. 観測点緯度経度と目的点緯度経度から基準方位角を算出
    - 2. 観測点標高と目的点標高から基準視高度を算出
    - 3. 基準方位角と基準視高度に、オフセット方位角とオフセット視高度を加算したものを検索中心とする。
    - 4. 日時情報メニューの日付を基準日付とする。
    - 5. 天体の数だけ繰り返す
      - 1. 基準日付から1日単位で検索期間だけ繰り返す。
        - 1. 時刻0:00から1分単位で24時間繰り返す
          - 1. 天体の方位角と視高度を算出
          - 2. 検索中心からどれくらい離れているか精度を算出して、許容範囲以内のをリストに追加する。
        - 2. 最高精度のベストの1分単位の時刻から前後60秒を1秒単位で算出して、さらにベストの時刻を秒単位で求める。
    - 6. 画面下部にリスト表示する。
  - 「時間帯」表示内容
    - 辻時刻が以下の範囲にあることが分かるように、時間帯の範囲を示す。
      - `0時<=x<天文薄明[始]`
      - `天文薄明[始]<=x<航海薄明[始]`
      - `航海薄明[始]<=x<夜明`
      - `夜明<=x<常用薄明[始]`
      - `常用薄明[始]<=x<日の出`
      - `日の出<=x<12時`
      - `12時<=x<日の入`
      - `日の入<=x<常用薄明[終]`
      - `常用薄明[終]<=x<日暮`
      - `日暮<=x<航海薄明[終]`
      - `航海薄明[終]<=x<天文薄明[終]`
      - `天文薄明[終]<=x<0時`
