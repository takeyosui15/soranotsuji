# TODOリスト

プロジェクトのやることリスト、気になること、AIからの提案を一元管理します。
このファイルを開くだけで、今やるべきこと・気にかかっていることが一覧できます。

## 運用ルール
- 完了したら `[x]` にチェックを入れる
- 不要になった項目は削除してOK
- 優先度が高いものを上に書く
- AIは作業中に発生した相談で決めた方針について「開発者とAIとの協議内容と決定事項（DECISION）」に追記する
- AIは作業中に気づいた改善案を「AIからの提案（SUGGESTION）」に追記する
- AIは記憶が整理されたり次にハンドオフしても大丈夫なように「AIのやることリスト（TODO）」に追記する
- AIは記憶が整理されたり次にハンドオフしても大丈夫なように「AIの気になること（CONCERN）」に追記する
- バグを直したら、教訓を `knowledge/bugs.md` にも記録する
- memo.md(依頼者のアイデア帳)の項目は、Claudeが「備忘録リスト（MEMO・優先順位なし）」へ1行ずつ移す。優先順位付きリストへの昇格は依頼者が行う(2026-09-20 第143)。
  Claudeがmemo.mdを編集し終えたら、依頼者がmemo.md全文をiPhoneのメモへ貼り直す(memo.mdが正・第144)
