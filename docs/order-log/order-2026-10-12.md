> これは「CDNが改ざんされたら、全利用者が一斉にやられる」「配信元が止まったら宙の辻が起動しない」「版の指定が緩い物(MathJax@3)は、向こうの都合で中身が変わる」という3つの弱さです。
> 実際、今回この箱から sourceforge.io に取りに行ったら 403 で拒まれました(ブラウザ以外を弾く設定)。配信を他人に預けていた形です。
> - **自前配信に変えました(vendor/)。** MapLibre 4.7.1・three 0.160.0・astronomy-engine 2.1.19・GeographicLib 2.2.0・qrcode-generator 1.4.4・Draco(都市モードの解凍)の全部を、npmの配布物そのままリポジトリに同梱し、出所・版・ライセンス・内容の指紋(sha384/sha256)を `vendor/MANIFEST.json` に記録しました。GeographicLib は sourceforge の配布物と npm 2.2.0 が同じ指紋であることを確かめて npm から取りました。QRコードは、jsDelivr がその場で作る .min(出所を再現できない)ではなく、npmの元ファイル(registry・jsDelivr・unpkg の3か所で同じ指紋)にしました。
> - **MathJax は撤去しました。** 実は使っていました(ヘルプの「気差係数(K)について」のTeX記法18行)。レビューが見つけてくれたので、HTMLの上付き文字と記号で書き直しました(数式のためだけに1MB超のライブラリとフォントを配る理由はありません)。使っていなかった GeographicLib の度分秒(DMS)も同梱しません。
> - **読み込み元の許可リスト(CSP)を index.html に入れました。** スクリプトは「自サイト+Googleのログイン(accounts.google.com/gsi/client)+ピッカー(apis.google.com)」だけ。インラインのスクリプトと eval は不可。通信先・画像・埋め込みは、2.の洗い出しそのままの許可リスト。プラグイン(object)は不可、`<base>` の差し替えは不可。CSPに引っかかった物はコンソールに「CSP違反」として残ります(機能が静かに止まらないように)。
>   - これを可能にするため、index.html にあった30箇所の `onclick="…"`(+forecast の2箇所)を全部、`data-click` 属性+1つの委譲リスナー+「呼べる関数の許可表」に書き換えました。属性の文字列を評価しない形です。three の読み込みも reset.html のスクリプトも、インラインから外部ファイルにしました。
>   - CSPの効き目: もし innerHTML の穴が残っていても、`<img onerror=…>` や `<script>` の注入は script-src 'self' が止めます(インラインが禁止なので)。4.の「型そろえ」と二重の守りです。
>   - meta で書くCSPには限界があります。埋め込み禁止(frame-ancestors)は書けません(GitHub Pages はヘッダーを出せない)。危ない操作は全て確認ダイアログの後なので、クリックジャッキングの実害は低いと見ています。
> - **致命的な穴を、レビューが見つけました。** GitHub Pages は Jekyll で配信するので、`.nojekyll` が無いと `vendor/` という名前のフォルダを配信しません。そのまま配ると、全利用者でアプリが起動しなくなっていました(ローカルの検査は素のHTTPサーバーなので全部通ってしまう)。リポジトリ直下に `.nojekyll` を置きました。**本番の soranotsuji リポジトリにも同じファイルが要ります**(rsyncは隠しファイルも写しますが、コミットに入っているかをご確認ください)。配信後に `https://soranotsuji.net/vendor/MANIFEST.json` が 200 で返れば大丈夫です(deploy-guide に追記しました)。
> - 既知の脆弱性(OSVで照会): MapLibre 4.7.1 に1件(CVE-2026-85061=属性文字列のサニタイザのバイパス、6.4.1で修正)。宙の辻は属性文字列が全て定数で、外部のスタイルJSONも読まないので、今は悪用できません。4→6は大きな版上げなので、別のラウンドで全走と実機を添えて上げます(todo)。three・astronomy-engine・qrcode-generator・GeographicLib は該当なし。
