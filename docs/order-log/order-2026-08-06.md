#### 4. 調査②: 検索中心「線」と「点」の結果が同じ — 今の季節は数学的に同じになります

これは面白い結果でした。結論: **8月の幾何では「同じになるのが正しい」**です。
仕組みをご説明します。
「線」モードの精度角距離は「基準点から辻オフセット点までの線分」への最短距離です。
天体の通り道が線分の**途中**の近くを通れば、点モードと違う(小さい)値になります。
ところが今の季節、太陽は高い空から辻オフセット点の**先(右)側**を通って沈むため、一日の最良点は線分の終点(=辻オフセット点)より右にあります。
線分上で一番近い点が**終点そのもの**になるので、線への距離=点への距離となり、精度角距離・検索中心方位角差・視高度差の3つが完全に一致します。
実測で裏を取りました(基準は初期値の富士山方向・オフセット+10°・太陽のみ8日間)。
- **8月6日開始**: 点と線の全行が完全一致(上の理屈の通り)。
- **12月1日開始**: 初日の精度角距離が点=15.28°・線=7.28°と**はっきり別の値**になりました(冬の太陽は線分の途中の下を通るため)。
つまり線モードの実装は生きていて、差が出る幾何なら差が出ます。
もう一点だけ確認させてください: 検索中心オプションを切り替えただけでは、結果の表は変わりません(表は**検索実行時**の条件のスナップショットで、精度角距離はワーカーが検索中に計算した値です)。
切り替え後に「検索」ボタンを押し直した上での比較でしたら、上の季節の理屈が答えです。
冬の日付で再検索しても点と線が同じでしたら、その時の条件を教えてください。
